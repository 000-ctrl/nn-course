# 神经网络讲义

一门可以离线打开、全程在浏览器里动手的神经网络课程。从单个神经元讲到 Transformer、扩散模型和大模型推理,每一章都有可拖动、可训练、能立刻看到结果的演示。

**在线访问:https://000-ctrl.github.io/nn-course/**

**本地打开:双击 `index.html`。** 不需要服务器、不需要装任何东西、不需要联网(字体走了 Google Fonts,断网会自动退回系统字体)。

```
19 个部分 · 约 7.4 万汉字正文 · 45 个交互演示 · 59 道随堂检验
单文件 860 KB · 无外部依赖 · 进度保存在浏览器本地
```

## 它是什么

一本**能动手的书**。每个抽象概念都配一个能改参数、能看变化的演示:

- 拖隐藏层神经元的数量,看决策边界从直线掰成曲线
- 让 SGD、动量、Adam 在同一份数据上赛跑,三条损失曲线并排
- 在 9×9 网格上手画图案,选卷积核,实时看特征图和池化
- 拖温度滑块,看下一个词的概率分布被锐化或抹平
- 自己搭网络:选层数、宽度、激活、优化器,一键训练,还会给出"过拟合 / 欠拟合"诊断

## 它不是什么

说清楚边界,免得你带着错误期待打开:

- **不是习题集**。只有 59 道选择题,没有计算题,没有作业批改。读完能读懂,不等于会推导。
- **不是 PyTorch 教程**。书里有代码片段和对照表,但训练都发生在页面内置的微型引擎里,不需要装环境。
- **不保证低端设备满帧**。第 6 章三网络赛跑和第 13 章最大档搭建器在中低端机器上会掉帧(实测见下文)。
- **不适合当论文索引**。第 14 章讲的是原理和工程直觉,不是最新模型的逐篇综述。

## 构建与自检

需要 Node.js(任意 18+ 版本),没有第三方依赖。

```bash
node build.mjs    # parts/ + src/ → index.html
node check.mjs    # 打包后自检
```

`build.mjs` 按文件名排序拼接 `parts/*.html`,所以新增章节只要把文件放进 `parts/` 并按下表的命名规则起名,无需改构建脚本(侧栏导航仍需在 `src/top.html` 里加一行)。

`check.mjs` 会检查:

- 每个内联脚本能否通过 `node --check`
- 全局 id 是否重复
- 每个 `.demo` 的 id 是否都有对应的 `defineDemo(id, …)`,有没有注册了却找不到元素的
- 章节是否用了 CSS 清单之外的 class
- 是否混入 `<style>`、内联 style、外部脚本、`alert`、`localStorage`
- 每章的正文汉字数、演示数、测验数

构建是**确定性**的:同一份 `parts/` 和 `src/` 重新打包,`index.html` 逐字节一致。

## 运行机制(概览)

成品是一个自包含的 HTML 文件,没有框架、没有打包器:

1. `src/head.html` 提供设计令牌(深浅两套)、排版与全部组件样式
2. `src/top.html` 是外壳:顶栏、侧栏目录、路由桩
3. `parts/*.html` 是 19 个 `<section class="ch">`,每章自带一个 `<script>` 注册演示
4. `src/end.html` 是核心运行时,提供:
   - `NN.MLP` —— 前向、反向传播、SGD / 动量 / Adam,纯 JS 实现
   - `NN.Plot` —— 折线 / 散点图,带悬停十字线
   - `NN.drawMatrix` —— 热力图(权重、注意力、卷积核)
   - `NN.drawNet` —— 网络结构图,边宽按权重、正负分色
   - `NN.renderBoundary` —— 二维决策边界
   - `NN.Data` —— 螺旋 / 双月 / 圆环 / 异或等数据集
   - 测验判分、章节进度、徽章、主题切换、路由

一次只渲染一章,其余 `hidden`;演示只在首次进入该章时初始化;训练全部走 `requestAnimationFrame` 分帧。细节见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 性能实测

在 Intel Core Ultra 7 155H 上,抽出页面里的引擎单跑(与浏览器同一个 V8):

| 场景 | 网络 | batch | 每步 | 每帧 10 步 |
|---|---|---|---:|---:|
| 第 00 章 | 2-8-8-2 | 16 | 0.048 ms | 0.5 ms |
| 第 04 章 | 2-16-16-3 | 32 | 0.145 ms | 1.5 ms |
| 第 06 章 | 2-32-32-3 | 64 | 0.502 ms | 5.0 ms |
| 第 13 章(最大档) | 2-64-64-64-3 | 64 | 2.836 ms | 28.4 ms |

60 fps 的预算是每帧 16.7 ms。前三个场景绰绰有余;第 13 章最大档会掉到 30 fps 左右,所以做了两处定点优化:

- 决策边界默认分辨率 56 → 44(3136 次前向降到 1936 次,每帧省约 4 ms)
- 第 13 章按参数量自动降步数:参数超过 4000 时每帧 8 步降为 3 步

没有做全局自适应降级。低端手机和老笔记本上,第 6 章和第 13 章仍可能掉帧。

## 质量与已知局限

18 章由并行的写作智能体产出,之后经历了逐章校验、跨章主编审查、零基础读者试读三轮检查。零基础试读的平均分从 **2.94 / 5 提升到 3.17 / 5**(抽六章复测)。

**已经解决的:**

- 全书 36 个记号都有中文读法和最小例子(之前 Σ、∂、∇、E 从未被解释)
- 每章标注了前置知识与可跳过的部分
- 跨章记号冲突(如 `Wx` 与 `XW` 的转置约定)已统一
- 重复讲解(梯度消失、BPE)已去重

**还没解决的:**

- 公式仍然难。符号会念了,但 `δ⁽ˡ⁾ = ((W⁽ˡ⁺¹⁾)ᵀδ⁽ˡ⁺¹⁾) ⊙ σ′(z⁽ˡ⁾)` 这样的式子,零基础读者只能读懂它后面的那句人话
- 没有计算题和自动判题,读者无法检验自己是否真的理解
- 没有人机答疑,卡住了只能自己查
- 审计本身有过误报(把正确的 `0.49` 判成错误、把有意的去重判成内容丢失),已有结论都经过人工复核

方法、数字与复检步骤见 [docs/QUALITY.md](docs/QUALITY.md)。

## 怎么改

- 改某一章:编辑 `parts/<章节>.html`,然后 `node build.mjs`
- 加一章:在 `parts/` 新建文件,同时改 `src/top.html` 的侧栏导航
- 改样式或设计令牌:`src/head.html`
- 改引擎或加新 API:`src/end.html`,注意别破坏已有调用

写作与改动的具体规范见 [docs/AUTHORING.md](docs/AUTHORING.md),硬性契约见 [src/CONTRACT.md](src/CONTRACT.md)。

## 环境与兼容性

- 浏览器:Chrome / Edge / Safari / Firefox 的最近两年版本。用到 `ResizeObserver`、`color-mix()`、`dvh`,老浏览器会降级但仍然可读。
- 没有任何网络请求,除了 Google Fonts 的字体文件;断网时自动使用系统字体。
- 学习进度、主题选择存在 `localStorage`,只在本机、不联网。
- 构建只需要 Node.js,不安装任何 npm 包。

## 部署

站点通过 GitHub Pages 发布,入口是仓库根目录的 `index.html`:

**https://000-ctrl.github.io/nn-course/**

更新流程:

```bash
node build.mjs      # 重新生成 index.html
node check.mjs      # 自检
git add -A && git commit -m "update"
git push origin main
```

Pages 会自动重新部署,通常一到两分钟生效。因为成品是纯静态单文件,不需要构建步骤,也不需要配置 `actions/`。
