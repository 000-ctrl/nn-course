# 质量是怎么测的

这本书的内容由并行的写作智能体产出,所以"看起来完整"不等于"读得懂"。下面是实际测过的流程、拿到的数字,以及**没有解决**的问题。

---

## 一、五轮检查

| 轮次 | 角色 | 智能体数 | 产出 |
|---|---|---:|---|
| 1 | 编写 → 校验 → 修订 → 跨章主编 | 65 | 18 章成稿;6 章一次通过,12 章经修订通过;主编挑出 12 个跨章问题 |
| 2 | 按主编意见修订 → 逐章复核 | 28 | 13/14 章通过;最后一条交叉引用手工补掉 |
| 3 | 零基础读者试读(18 章)+ 归纳 | 19 | 平均 2.94/5;16 章"能读但有几处硬卡";0 章完全读不懂 |
| 4 | 符号速查页 + 18 章首现定义补丁 + 复核 | 37 | 符号表 36 条;18 章全部加前置标注 |
| 5 | 抽六章复测 | 6 | 2.94 → 3.17 |

合计约 **155 次智能体启动、1,000 万输出 token、3,800 次工具调用**。

---

## 二、试读是怎么做的

给每个智能体一个人设,让它像真实读者一样从头读到尾:

> 32 岁,文科本科,高中数学勉强及格,微积分忘光;没写过代码,会用 Excel。不会上网查资料,卡住就是卡住。

要求它回答四件事:

1. 哪一句真正让你停下?**原样摘录**,不要改写
2. 这一章用了哪些本章和前面都没解释的概念、符号或缩写
3. 公式里的符号在前文有没有定义
4. 如果完全跳过代码块,这一章的论证还站得住吗

评分标准:1 = 完全看不懂,3 = 能读但有几处硬卡,5 = 一路顺畅。

### 结果

```
第 00 章 3    第 09 章 2.5    第 A 章 3
第 01 章 3    第 10 章 3       第 B 章 3
第 02 章 3    第 11 章 2.5     第 C 章 3
第 03 章 3    第 12 章 3
第 04 章 3    第 13 章 3
第 05 章 3    第 14 章 3
第 06 章 3
第 07 章 3
第 08 章 3
```

归纳出的系统性问题(按影响广度):

1. **符号没教过怎么读**——`Σ ∂ ∇ E[·] ‖·‖ ⊙ ⌊⌋` 首次出现既无读法也无含义,影响 11 章
2. **拿英文名当定义**——"隐藏层""特征图""秩""码本"给了词,没给画面
3. **跨章顺序倒置**——第 1 章先用 sigmoid,1.4 才定义;第 4 章用 softmax,第 6 章才讲
4. **一符多义**——`L` 同时是损失和层数,`p` 同时是预测和概率

## 三、审计也会错:四次误报

这是这一节存在的理由。审计员和作者是同一个模型,共享同样的盲区,所以**它给的结论必须验算**。

| 报告说 | 实际 | 结论 |
|---|---|---|
| `(2.3−3)²` 应得 0.98,书写成 0.49 | 0.49 才是对的,报告漏了平方外层的系数 | 误报 |
| `½[(1−0.01)²+0.01²+0.01²]` 算错 | 0.49 正确,报告漏了括号 | 误报 |
| "16.5 被取整成 16" | 全文搜不到 16.5 | 误报 |
| 第 9 章"丢了一个演示和整段数字" | 是上一轮**明确要求**去重的内容 | 误报 |
| A.8 标题"八件工具",表里 10 条 | 属实,已改 | **真问题** |

四条经检验的"硬错"里只有一条成立。所以现在的规矩是:

> 任何"数字错了"的结论,必须当场独立验算;任何"内容丢了"的结论,必须比对补丁前的快照并确认删除是否有意。

## 四、当前的真实状态

**已经解决的**

- 36 个记号都有中文读法和最小例子
- 每章标注前置知识与可跳过的部分
- 跨章记号冲突(`Wx` / `XW` 的转置约定)统一
- 重复讲解(梯度消失、BPE)去重
- 六章复测里 09 和 11 从 2.5 升到 3,12 从 3 升到 4

**没有解决的**

| 问题 | 为什么没解决 |
|---|---|
| 公式仍然读不懂 | 符号会念不等于会推导。`δ⁽ˡ⁾ = ((W⁽ˡ⁺¹⁾)ᵀδ⁽ˡ⁺¹⁾) ⊙ σ′(z⁽ˡ⁾)` 这类式子需要数学训练,不是补一句白话能解决的 |
| 没有计算题和判题 | 需要一个题目系统和答案校验器,是独立工程 |
| 答疑缺失 | 静态页面无法回答问题 |
| 低端设备掉帧 | 只做了两处定点优化,没有全局自适应降级 |
| 没有行为测试 | `check.mjs` 只查结构,不查演示是否真的跑起来了 |

**已知的内容风险**

- 第 9、11 章仍是全书最难的两章(复测 3 分)
- 第 14 章偏重概念,不覆盖最新模型的具体实现
- 某些数字是作者手算的,只抽查了被审计点名的部分,没有全量复核

## 五、怎么复检

结构检查(每次改完必跑):

```bash
node build.mjs && node check.mjs
```

它检查语法、重复 id、演示注册、类名白名单,以及每章的字数/演示数/测验数。但**它不检查内容对不对**。

内容复检需要人或者独立的读者。如果想重跑试读,给每个智能体的提示至少包含:

- 具体的人设(年龄、学历、是否写过代码、是否愿意查资料)
- 要求**原样摘录**卡住的句子,不许改写、不许概括
- 明确"不要为了礼貌给高分,也不要为了挑刺而挑刺"
- 要求它区分"作者忘了交代前提"和"我自己没动脑"

拿到报告后,**先验算再动手**。上面四次误报就是教训。
