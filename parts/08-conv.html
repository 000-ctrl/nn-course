卷积网络

用一个小窗口滑过整张图,把局部边缘逐层组合成物体,顺便把参数量砍掉三个数量级。

读前第 02 章的展平与全连接、第 03 章的学习率、第 04 章的 ReLU、第 05 章的反向传播、第 06 章的 epoch;第 07 章的过拟合与数据增强用于 8.4—8.6。可跳过8.4 节的网络年表、8.6 节的 PyTorch 代码块;不影响 8.1—8.3 主线。

一张 224×224 的彩色照片有 150,528 个数。把它拉直送进全连接层,只第一层(1000 个隐藏单元)就需要 1.5 亿个权重。更糟的是,图像左上角的像素和右下角的像素被当成两列毫不相干的数字。卷积网络(convolutional network,CNN)用两个假设同时解决这两件事:相邻像素有关,这叫局部性(locality);同一图案出现在哪里都还是同一图案,这叫平移不变性(translation invariance)。

8.1图像是三维张量

一张彩色图在计算机里是三维张量(tensor):高 H、宽 W、通道数(channel)C。RGB 图的 C=3;一批 32 张 224×224 的图是 32×3×224×224。灰度图 C=1,所以手写数字常写成 28×28×1。全连接层必须先把它展平(flatten)成一列 150,528 个数,这个动作同时丢掉了两样东西:哪些像素挨着谁,以及这个图案在图的哪个位置。

局部性说的是:判断一个像素是不是猫耳朵的尖端,你不需要看整张照片,看它周围 5 个像素就够了。平移不变性说的是:同一只猫在左上角或右下角,都应该激活同一组“猫耳检测器”。卷积的做法是把一个很小的权重窗口拴在整张图上滑动,每个位置都用同一组权重,这叫权重共享(weight sharing)。一个 3×3、输入 3 通道的卷积核只有 3×3×3+1=28 个参数;在 224×224 的图上,它被重复使用 50,176 次。参数不随图像尺寸增长,这是 CNN 与全连接层最根本的差别。

严格地说,卷积提供的是平移等变(equivariance):输入里的猫耳向右移 10 像素,特征图里的响应也向右移 10 像素,而不是保持不变。真正的不变性来自后面的池化、全局池化和数据增强。这个区别在调试时很有用:特征图跟着移动是正常的,不跟才说明哪里错了。

8.2卷积核:一个可学习的小窗口

卷积核(kernel,也叫滤波器 filter)是一个小矩阵,常见尺寸 3×3 或 5×5。它覆盖输入的一小块,把对应位置的数字逐项相乘再求和,加一个偏置(bias),最后通常过一层 ReLU。对单个输出位置,计算是:

yi,j = Σc,u,v Kc,u,v · Xc, i·s+u−p, j·s+v−p + b

其中 K 是卷积核权重,X 是输入,Σ 是求和(sum),c 遍历输入通道,i,j 是输出位置,u,v 是窗口内偏移,b 是偏置,s 是步幅,p 是填充。用人话说:窗口在图上每次挪 s 格,窗口内做一次加权求和。卷积核里的数字不是人定的,是反向传播学出来的。训练开始前它们是随机小数,训练后第一层常长出类似边缘检测器的图案,但那是结果,不是前提。

两个超参数决定输出尺寸。步幅(stride)是窗口每次移动的格数;填充(padding)是在图像四周补零的圈数,补 p=1 能让 3×3 卷积的输出和输入一样大。输出边长的公式是:

Hout = ⌊(H + 2P − K) / S⌋ + 1

K 此处指核边长(kernel size),非权重;P/S 即 padding/stride;⌊⌋ 是向下取整(floor)。代入数字:32×32 输入、5×5 核、P=2、S=1,输出 (32+4−5)/1+1=32;把步幅改成 2,输出 16;224×224 输入、7×7 核、P=3、S=2,输出 112,这正是 ResNet 的第一层。尺寸算错是初学者最常见的报错来源,写网络前先把每一层的 H_out 算一遍。

一个卷积核产生一张特征图(feature map)。想要 16 个特征,就用 16 个核,输出就是 16 个通道。输入 3 通道、输出 16 通道的 3×3 卷积,参数量是 3×3×3×16+16=448;同样把 150,528 维输入接到 16 个神经元,全连接层要 240 万个参数。1×1 卷积只做通道混合,不跨空间,参数量 C_in×C_out;64 通道到 256 通道只要 16,384 个参数,常用来升降维。

上面的“边缘”“模糊”“浮雕”是为了让你看清卷积在做什么,它们是手写死的。真实网络里的核全部由损失函数学出来,同一层 64 个核会分工成不同的方向边缘、颜色斑块和纹理。换一个任务,比如识别细胞核或雷达回波,第一层学到的图案会和自然图像很不一样。把核当成“必须像 Sobel 算子”会限制你对网络的想象,也会让你在可视化时误以为模型坏了。

8.3池化、下采样与感受野

池化(pooling)是在特征图上再做一次小窗口聚合,最常见的是 2×2 最大池化(max pooling):每个 2×2 块取最大值,步幅 2,输出边长减半。13×13 的特征图池化后是 6×6,丢掉最后一行一列。池化没有参数,不做乘法,作用有三个:减少后续计算量、扩大后续神经元的感受野、让响应对一两个像素的位移不那么敏感。平均池化(average pooling)取均值,保留整体强度;全局平均池化(global average pooling,GAP)把每张特征图压成一个数,常用来替代最后的全连接层,ResNet 就是这样把 7×7×2048 压成 2048 维再分类。

池化不是非有不可。很多现代网络用步幅为 2 的卷积做下采样,让网络自己学怎么压缩;但 2×2 最大池化简单、稳定,仍然是理解 CNN 的标准零件。

感受野(receptive field)是输出特征图上一个神经元,能“看到”原始输入的多大区域。一层 3×3 卷积的感受野是 3×3;两层叠起来是 5×5;三层是 7×7。一般递推公式是:

rl = rl−1 + (kl − 1) · jl−1,   jl = jl−1 · sl

这里 j 是相邻输出点在输入上的间距。代入一个带下采样的栈:3×3 卷积(步幅 1)后感受野 3;2×2 池化(步幅 2)后 4;再来一层 3×3 卷积,感受野变成 4+(3−1)×2=8。深度带来的是指数级的覆盖增长。ResNet-50 最后一个特征点理论感受野约 483 像素,已经超过 224 的输入边长;这也是深层网络能判断“整只猫”而不是“一条边”的原因。

8.4从 LeNet 到 ResNet

1998 年 LeCun 的 LeNet-5 用 7 层、约 6 万个参数识别 32×32 的灰度手写数字,结构是“卷积—池化—卷积—池化—全连接”,已经具备今天 CNN 的全部骨架。2012 年 AlexNet 把深度加到 8 层、参数 6000 万,在 120 万张 ImageNet 图像、1000 类上把 top-5 错误率从 26.2% 降到 15.3%,关键改动是 ReLU、Dropout、两块 GPU 和数据增强。2014 年 VGG-16 证明“全部用 3×3 卷积、堆到 16 层”也有效,代价是 1.38 亿参数。两个 3×3 卷积的感受野等于一个 5×5,参数量却是 2×9C²=18C² 对 25C²,还多了一次非线性,所以小核堆叠比大核划算。

网络年份深度参数量关键想法

继续加深会撞上一堵墙。研究者发现 56 层的普通网络,训练误差反而比 20 层的更高;这不是过拟合,因为训练集上的误差都降不下去,而是优化变难了。ResNet 的答案是残差连接(residual connection):不让一层直接学目标映射 H(x),而让它学残差 F(x)=H(x)−x,输出写成:

y = F(x) + x

如果这一层什么都不做最好,把 F(x) 压到 0 比把 H(x) 学成恒等映射容易得多。加法那条捷径(shortcut)没有参数,梯度可以原样流回去,深层网络因此能训练。ResNet-152 有 152 层,ImageNet top-5 错误率 3.57%;它的残差块通常是“1×1 降维—3×3 卷积—1×1 升维”的瓶颈结构,50 层版本只有 2560 万参数,约为 VGG 的 1/5。BatchNorm 放在卷积和 ReLU 之间,把每层输入拉回稳定分布,让更深的网络能用更大的学习率。

今天你看到的所有视觉骨干——ResNet、EfficientNet、ConvNeXt——都还在用“局部卷积 + 归一化 + 残差 + 下采样”这套组合。理解这四件套,比记住某个网络的层数更有用。

8.5迁移学习:别从随机权重开始

从头训练 ResNet-50 需要 128 万张图、1000 个类别和数百万次参数更新。你手上可能只有 300 张标注好的电路板缺陷图。这时正确的起点不是随机初始化,而是迁移学习(transfer learning):拿一个在 ImageNet 上训练好的网络,它已经学会了边缘、纹理、材质和部件,这些特征对很多任务都能复用。

  1. 冻结骨干(freeze backbone)。把卷积层的 requires_grad 设为 False,让它们不更新。
  2. 换头。把最后的 1000 类全连接层换成 Linear(2048, 10),新头随机初始化。这一步只有约 2 万个参数需要训练。
  3. 先训头。学习率 1e-3,20 个 epoch,通常几分钟就能得到一个不差的基线;数据极少时这叫线性探测(linear probe)。
  4. 再整体微调(fine-tune)。解冻全部层,学习率降到 1e-4 左右,再训 10—30 个 epoch。预训练权重已经接近好解,学习率太大会把它们冲掉。

两个细节容易踩坑。第一,BatchNorm 的滑动均值是在 ImageNet 上统计的,小批量微调时不要让它乱跑,可以冻结 BN 的统计量,或者把 batch 调到 32 以上。第二,数据增强要符合任务语义:自然图像左右翻转通常无害,但医学影像的左右翻转可能把病灶位置改错,文字图像翻转后直接不再是同一个字。

实践顺序

先冻结骨干、只训新头,记录验证集准确率;如果它明显低于你的预期,再解冻最后两三个 stage 微调,而不是一上来就全网络放开。每改一次,只动一个变量,你才知道收益来自哪里。

8.6写一个能跑的小 CNN

下面这段 PyTorch 代码输入 8×3×32×32,经过两组“3×3 卷积 + ReLU + 2×2 池化”,展平后接 10 类全连接层。模型一共 25,578 个参数,在 CPU 上训练几千张 32×32 的图毫无压力。注意每一层的尺寸注释:32 池化到 16,再池化到 8,所以展平后是 32×8×8=2048。

python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, stride=1, padding=1),  # 8x3x32x32 -> 8x16x32x32
    nn.ReLU(),
    nn.MaxPool2d(2),                                       # -> 8x16x16x16
    nn.Conv2d(16, 32, kernel_size=3, stride=1, padding=1), # -> 8x32x16x16
    nn.ReLU(),
    nn.MaxPool2d(2),                                       # -> 8x32x8x8
    nn.Flatten(),                                          # -> 8x2048
    nn.Linear(32 * 8 * 8, 10)                              # -> 8x10
)

x = torch.randn(8, 3, 32, 32)
print(model(x).shape)                          # torch.Size([8, 10])
print(sum(p.numel() for p in model.parameters()))  # 25578

opt = torch.optim.Adam(model.parameters(), lr=1e-3)
