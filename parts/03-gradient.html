梯度与学习

把"错得多离谱"压缩成一个数,再沿着让这个数变小的方向挪动参数(parameter)。

第 02 章里,你已经能把一层层的加权求和写成矩阵乘法。但网络不会自己变好:它需要有人告诉它"现在错在哪里、该往哪边调"。这件事的全部数学只有三个词——损失(loss)、导数(derivative)、梯度(gradient)。这一章把它们拆开,再装回去。读完你会知道训练循环里那行 w -= lr * grad 到底在做什么,以及它为什么经常失败。

3.1损失函数:给"错"打一个分

训练一个网络,第一步不是写代码,而是决定"什么叫好"。损失函数(loss function)就是这把尺子:它把模型在当前参数下犯的所有错误,压缩成一个标量(scalar)。标量就是一个数,不是一组数。这个数越小,模型在这批数据上越接近你的期望;训练的全部目标,就是让这个数变小。

以回归(regression)为例:你要预测房价,模型对第 i 个样本输出 ŷ_i,真实答案是 y_i。最常用的尺子是均方误差(mean squared error, MSE):

L = (1/n) Σ (ŷi − yi)²

用普通话念一遍:Σ 是求和(summation),误差(residual,即预测减真值)先平方,再把 n 个样本平均。平方做两件事——把正负误差都变成正数,并且让大误差受到更重的惩罚。假设三个样本的误差分别是 0.1、−0.2、0.9,平方后是 0.01、0.04、0.81,平均得到 L = 0.287。若把那个 0.9 的误差降到 0.3,L 立刻变成 0.047,下降 84%。这就是损失函数的价值:它逼模型优先修最离谱的那几个预测。

分类任务常用交叉熵(cross-entropy)。模型对真实类别给出概率 p,损失就是 −log p(负对数似然 negative log-likelihood:真实类别概率越小,罚得越重):猜对且自信(p = 0.99)时损失 0.010;猜对但犹豫(p = 0.5)时 0.693;把真实类别的概率压到 0.01 时,损失 4.605。三个数字直接对应"错得多离谱",模型没有任何模糊空间。

关键的一点:损失不是某一个参数的函数图像上随便一条线,而是全部参数的函数。一个有 13,002 个参数的迷你网络,它的损失地形(loss landscape)是一张 13,003 维空间里的曲面(13,002 个参数加 1 个损失值)。你没法画出来,但所有直觉都可以先在二维里练熟,再原样搬到高维。

先定尺子,再谈优化损失函数定义了"好"的标准。换一个损失,就是换一个训练目标:MSE 关心平均偏差,交叉熵关心正确类别的概率,绝对值损失对离群点更宽容。网络不会"自己知道"你想要什么,它只会最小化你给它的那个数。

3.2导数:斜率就是方向

先只看一个参数 w。固定其他一切,损失变成一条曲线 L(w)。导数(derivative)是这条曲线在某一点的切线(tangent line)斜率,记作 dL/dw。它的定义是一个极限(lim,即 limit:让 h 无限接近 0):

dL/dw = limh→0 (L(w+h) − L(w)) / h

你不需要会算极限,只需要记住导数的两个用途。第一,符号告诉你方向:斜率为正,说明 w 增大时损失增大,那就该把 w 调小;斜率为负,说明 w 增大时损失减小,那就该把 w 调大。第二,绝对值告诉你敏感度:斜率 4 意味着 w 挪动 0.01,损失大约变化 0.04;斜率 0.02 意味着同样挪动只变化 0.0002。

拿一个能手算的例子:L(w) = (w − 3)²。它的导数是 2(w − 3)。在 w = 5 处,斜率是 4,损失是 4;想让损失变小,应该减小 w,比如走到 4.6,损失变成 2.56。反过来,在 w = 1 处斜率是 −4,应该增大 w。导数像山坡上的倾斜仪:它不告诉你山脚在哪,只告诉你脚下这一点的坡朝哪边、有多陡。

严格说,导数是"局部"信息。它保证的是:只要步子足够小,沿着负斜率方向走,损失一定下降。步子一大,这个保证就失效——3.4 节会看到它失效时的样子。

3.3梯度:把"方向"推广到多个参数

网络有成千上万个参数,损失对每个参数都有一个偏导数(partial derivative,写作 ∂、读作偏导):固定其他参数,只对一个参数求导。把所有偏导数按参数顺序排成一个向量(vector),这个向量就叫梯度(gradient,写作 ∇、读作梯度):

∇L = (∂L/∂w1, ∂L/∂w2, …, ∂L/∂wn)

梯度有两个性质,值得背下来。第一,它指向损失上升最快的方向;第二,它的长度是那个方向上的上升速率。所以想让损失下降,就要往梯度的反方向走。这就是梯度下降(gradient descent):

w ← w − η ∇L(w)

其中 η 是学习率(learning rate),下一节专讲。用普通话读:新参数 = 旧参数 减去 学习率 乘以 梯度。减号是全部秘密所在——梯度指上坡,减号让你下坡。

一个两参数的具体例子:L(w1, w2) = w1² + 3w2²。偏导数是 ∂L/∂w1 = 2w1,∂L/∂w2 = 6w2。在点 (1, 2) 处,梯度是 (2, 12)。这个向量指向右上方,因为往 w2 方向走 1 个单位,损失涨得比 w1 方向快 3 倍。取学习率 0.1,下一步是 (1 − 0.2, 2 − 1.2) = (0.8, 0.8),损失从 13 降到 0.64 + 1.92 = 2.56。一步就砍掉 80%。

损失 L(w) = (w − 3)²,当前 w = 5,导数为 4。下一步应该往哪边调?

常见误解:梯度就是参数更新的方向梯度指向损失上升最快的方向,不是下降方向。更新公式里的减号不是记号习惯,而是把方向翻过来的必要操作。如果你在代码里写成 w += lr * grad,损失会稳定地变大,训练会稳定地变差。看到 loss 曲线一路上扬,先检查这个符号。

3.4学习率:一步走多远

学习率决定每次沿负梯度方向挪多远。它是训练中最重要的超参数(hyperparameter)之一,因为同一个梯度配上不同的步长,结果可以完全相反。

看一个二次函数 L(w) = (w − 3)²,梯度 2(w − 3)。在 w = 3.5 处梯度是 1。学习率 0.1,下一步 w = 3.4,损失从 0.25 变成 0.16;学习率 0.5,下一步 w = 3.0,一步到位;学习率 1.2,下一步 w = 2.3,越过谷底到了另一边,损失仍是 0.49;再下一步跳到 3.98,损失变成 0.96,比上一步更大——它在谷底两侧来回弹,而且越弹越远。学习率超过 2 除以曲线的曲率(curvature),也就是二阶导数(second derivative,斜率的变化率),梯度下降就会发散(diverge)。原因是每步把离谷底的距离乘以 1 − 学习率×曲率;这个因子要落在 −1 到 1 之间,学习率就必须小于 2/曲率。对这个函数,曲率恒为 2,临界值是 1。实际网络里曲率随位置变化,临界值不是一个固定数字,但"步子不能超过谷宽"这条直觉一直成立。

太小也不行。学习率 0.001 时,同样从 w = 3.5 出发,一步只挪 0.001;要把离谷底的距离从 0.5 缩小到 0.05,需要约 1150 步。工程上的常见做法是从 0.001 或 0.01 试起,观察头 100 步的损失曲线:下降太慢就乘 3,开始抖动就除以 3。现代优化器还会让学习率随训练衰减,或对每个参数单独调整步长。

3.5链式法则:责任沿链条传递

网络不是一层。输入 x 经过第一层得到 h,再经过第二层得到输出 ŷ,损失 L 又是 ŷ 的函数。你要知道 L 对第一层权重(weight)w 的导数,但 L 的表达式里根本没有 w,它藏在两层之外。链式法则(chain rule)解决这件事:把沿途每一小段的局部导数乘起来。

dL/dw = (dL/dŷ) · (dŷ/dh) · (dh/dw)

直觉是"责任传递"。最终损失对输出的敏感度,乘上输出对中间表示的敏感度,再乘上中间表示对权重的敏感度,就是损失对这个权重的敏感度。每一层只负责算自己那一段的局部斜率,然后把上游传下来的责任继续往下乘。反向传播(backpropagation)不是一条新数学,它就是链式法则在计算图(computation graph)上的高效执行顺序:从损失出发,从后往前,每个节点把收到的梯度乘上自己的局部导数再转发。

用数字走一遍:L = (3w + 1)²,w = 0.5。令 z = 3w + 1 = 2.5。dL/dz = 2z = 5,dz/dw = 3,所以 dL/dw = 15。若 w 增加 0.01,损失大约增加 0.15(精确值是 0.1509)。把链条拉长到 10 层,每层局部导数都是 0.25,那么最前面那层的梯度要乘 0.25 十次,等于 9.5×10⁻⁷——信号在传递中几乎消失,这就是消失梯度(vanishing gradient)。反过来每层乘 4,十层后放大到 1,048,576 倍,就是爆炸梯度(exploding gradient)。深度网络训练不稳,一大半原因在这条乘法链上。

3.6局部最小、鞍点,以及"看起来走不动"

梯度为零的点叫临界点(critical point)。它有三种可能。第一种是局部最小(local minimum):四周都比它高,梯度下降会停在这里。第二种是局部最大(local maximum):四周都比它低,梯度下降不会停在这里,除非初始化(initialization)恰好落在上面。第三种最容易被忽略:鞍点(saddle point)——在有些方向上它是谷底,在另一些方向上它是山顶。二维里鞍点像马鞍:沿马背方向下凹,沿马腹方向上翘。站在鞍点上,梯度是零,你会以为到了终点,但朝正确的方向迈一步,损失还能继续下降。整张地形上最低的那个点叫全局最小(global minimum),它可能只有一个,也可能有很多个等价的位置。

高维空间里,鞍点比局部最小多得多。一个 n 维临界点,要成为局部最小,所有 n 个方向都得向上弯;只要有任意一个方向向下弯,它就是鞍点。随机初始化下,这个概率随维度上升而迅速下降。所以"训练卡住"更常见的原因是鞍点、平坦区(plateau)或学习率不合适,而不是真的掉进了一个完美的局部最优。

实用对策有三类。加一点噪声或使用小批量(mini-batch)的随机梯度下降(stochastic gradient descent, SGD),噪声会把参数从鞍点附近推出去。加动量(momentum),让更新记住上一步的方向,冲过浅坑和小平台。或者换更好的初始化、调整学习率。理解这些方法的前提,是先把"梯度为零"和"已经最优"分开——它们不是一回事。

3.7在代码里跑一遍

下面这段纯 numpy 代码复现了第一个演示的核心:手写损失、手写导数、循环更新。保存成 .py 就能运行。把 lr 从 0.10 改成 0.70,观察它从收敛变成发散。

python
import numpy as np

# 损失 L(x) = 0.5x^4 - x^2 + 0.2x + 1
def loss(x):
    return 0.5 * x**4 - x**2 + 0.2 * x + 1

# 解析导数:2x^3 - 2x + 0.2
def grad(x):
    return 2 * x**3 - 2 * x + 0.2

x = 1.55          # 起点
lr = 0.10         # 学习率:试着改成 0.70
for step in range(40):
    g = grad(x)
    x = x - lr * g
    if step % 5 == 0:
        print(f"step {step:2d}  x={x:+.4f}  L={loss(x):.4f}  dL/dx={g:+.4f}")

输出会显示 x 从 1.55 快速靠近 0.95 附近的局部最小,损失从约 1.79 降到 0.70 以下,斜率随之趋近 0。把 lr 改成 0.70,你会看到 x 在两翼之间来回跳,数值迅速变大,几行后变成 nan 或天文数字。

真实框架不会让你手写导数。PyTorch 的自动微分(automatic differentiation)会记录前向计算图,调用一次 backward() 就按链式法则把梯度算好,存在每个参数的 .grad 里:

python
import torch

w = torch.tensor([0.5], requires_grad=True)
x = torch.tensor([3.0])
y = torch.tensor([10.0])

for step in range(20):
    y_hat = w * x                 # 前向:一个最简单的线性模型
    loss = ((y_hat - y) ** 2).mean()
    loss.backward()               # 反向:链式法则自动执行
    with torch.no_grad():
        w -= 0.01 * w.grad        # 梯度下降
        w.grad.zero_()            # 清空累积的梯度
    if step % 5 == 0:
        print(step, w.item(), loss.item())

这段代码的最优解是 w = 10/3 ≈ 3.333。梯度 6(3w − 10) 在 w = 0.5 时是 −51,学习率 0.01 给出每步 +0.51 的修正,大约 20 步收敛到 3.3 附近。zero_() 那一行常被初学者漏掉:PyTorch 的梯度是累加的,不清零就会把上一步的梯度也带进来。训练循环的骨架到这里就齐了——前向算损失,反向算梯度,沿着负梯度挪参数,重复。
