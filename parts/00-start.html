先给结论:神经网络(neural network)是一类带参数的函数;训练(training)就是用数据把这组参数调到「输出尽量接近答案」。这一章不推导复杂公式,先把这句话讲透,再告诉你全书怎么读、演示怎么用。

0.1神经网络只做一件事:用数据拟合函数

神经网络不是一套写好的规则,而是一个函数。你给它输入 x,例如一张 28×28 的灰度图;它输出 y,例如「这张图是数字 7 的概率为 0.93」。函数内部做的事,归根到底是许多次加权求和,再穿插几次简单的非线性变换。参与求和的系数叫权重(weight),额外的常数叫偏置(bias),它们合称参数(parameter)。一个 2→16→16→2(2 输入→两层各 16 单元→2 输出)的小网络有 354 个参数,数字不大,却足以围出一个闭合的环。

手写规则的思路是先把条件想清楚,再写进代码。判断垃圾邮件,你可能会写:同时出现「中奖」「汇款」「点击链接」就拦截。发件人把「中奖」写成「中奬」,规则立刻失效;你再补一条,再补一条,补到 300 条时,规则开始互相矛盾,维护成本超过收益。学习的思路相反:准备 5,000 封人工标注(label)过的邮件,让程序自己找一组参数。没有人告诉它「中奬」是错别字,它从字符组合的统计里学到这两个词很像。

差别不在谁更聪明,而在知识写在哪里。规则把知识写在人的代码里,学习把知识写在参数里。参数可以批量更新:改 354 个数,比改 3,000 行 if 容易;同一套训练代码换一份数据就能重跑。代价是,你必须相信数据、检查数据,并且接受模型可能学到你不想要的东西。

一句话神经网络 = 选一个函数形状 f,用数据定它的参数 θ。所谓「学习」,就是在一个事先定好的损失函数上做数值优化。
y = f(x; θ)　　θ* = argminθ (1/N) Σ L(f(xi; θ), yi)

普通话翻译:Σ 是求和(sigma),argmin 是取使后面式子最小的参数。在所有候选参数 θ 里,挑一个让 N 个样本的平均损失(loss)最小的。L 衡量「预测和答案差多少」,常见的一种是交叉熵(cross-entropy),第 01 章会具体算。梯度(gradient)告诉你,参数往哪个方向挪一点,损失下降最快。整本书剩下的内容,基本都在回答三个问题:函数形状怎么选、参数怎么更新、怎样判断它真的学会了。

这里要先泼一盆冷水:神经网络不保证「理解」。它保证的是在训练分布上把损失压低。数据里有偏见,它会学偏见;标签有错误,它会学错误;测试场景和训练场景差得远,它的准确率会掉。把这一点记住,后面每学一个技巧,你都会多问一句:它到底在优化什么?

0.2规则与学习:差距可以量出来

下面用一组人造数据把差距量出来。240 个点分两类:内圈半径约 0.55,外圈半径约 1.3,各 120 个。一条直线 a·x1 + b·x2 = c 把平面切成两个半平面:它可以切掉外圈的一小块,却没法把内圈整个包起来。所以线性判据的准确率(accuracy)上限大约 71%,这不是调参问题,而是函数形状不够。真正让边界拐弯的,是隐藏层(hidden layer,夹在输入输出之间的层)里的折线函数,例如修正线性单元(ReLU,rectified linear unit):它把负数压成 0,正数原样通过。右边的小网络还是 354 个参数,在同样的 240 个点上训练了 400 步,每步抽 32 个点,学习率(learning rate)0.03,优化器(optimizer)Adam,最后学到的是一个闭合的环。

拖动滑块时注意两件事。第一,准确率很难超过 72%:直线没有「半径」这个概念,它最多切掉外圈的一块,围不住内圈。第二,右侧网络的边界不是完美的圆,边缘有些毛刺;这来自有限参数和有限训练步数。把 a、b 都拖到 0,直线消失,判据退化成「全部预测同一类」,准确率正好 50%。你也可以点「重新初始化并训练」,换一组随机初始值从头跑 400 步。两次的准确率通常都能到 100%,但边界毛刺的位置不同:数据有限时,同样好的解不止一个。

常见误解网络参数越多,效果一定越好。参数多只代表容量(capacity)大,不代表泛化(generalization)好,也更容易过拟合(overfitting)。上面 354 个参数的网络能到 97%,但换 240 个带 30% 错标的点,它同样会用 354 个参数把错误背下来。决定上限的首先是数据质量和任务本身,其次才是模型大小。

0.3一次训练的全过程

第二个演示自动循环播放一次 300 步的训练。左边是决策边界(decision boundary),右边是损失曲线。开始那一帧,边界是一条直线:我把网络的前两个隐藏单元(hidden unit)初始化成一对互补的 ReLU(同一输入 z 分别过 ReLU(z) 与 ReLU(−z),相减得 z),让两者的差恰好等于一个线性函数。这样你能看到从线性到非线性的全过程,而不是一上来就随机弯折。

训练每帧走 2 步,每步 32 个点。损失从 0.7 附近降到 0.1 以下,训练集(training set)准确率从 63% 左右升到接近 100%。300 步之后停 1.5 秒再重播。右图的损失会抖:小批量(mini-batch)每次只抽 32 个点,梯度有噪声,这是随机梯度下降(stochastic gradient descent, SGD)的常态。把所有训练样本完整过一遍叫一轮(epoch):演示里 220 个点、每步抽 32 个,一轮大约 7 步,300 步约 44 轮。看趋势,不要看单个点。

留意边界弯曲的方式:它不是一次性变成圆,而是先在一个角上鼓出来,再逐渐围拢。这就是隐藏层(hidden layer)的工作方式——每个 ReLU 单元贡献一条折线,16 个单元拼出许多段折线,折线足够多,就能逼近弯曲的边界。第 04 章会把这件事画成网格:同样 16 个单元,为什么有的摆法能分开月牙,有的不能。

0.6第一个可运行的例子

下面这段 PyTorch 代码和演示里的网络同构:2 个输入、两层 16 个隐藏单元、2 个输出。数据是 240 个随机点,半径大于 1 记为类别 1。现在不必看懂每一行,只需认出三件事:模型定义、损失函数、backward 与 step。第 06 章会把它们逐行拆开。

python
import torch, torch.nn as nn

# 240 个二维点:半径大于 1 记为类别 1
X = torch.randn(240, 2)
y = ((X[:, 0] ** 2 + X[:, 1] ** 2) > 1.0).long()

model = nn.Sequential(
    nn.Linear(2, 16), nn.ReLU(),
    nn.Linear(16, 16), nn.ReLU(),
    nn.Linear(16, 2)
)
opt = torch.optim.Adam(model.parameters(), lr=0.03)
loss_fn = nn.CrossEntropyLoss()

for step in range(400):
    logits = model(X)                 # 前向:算预测
    loss = loss_fn(logits, y)         # 损失:预测和标签差多少
    opt.zero_grad()                   # 清空上一步梯度
    loss.backward()                   # 反向:算每个参数的梯度
    opt.step()                        # 更新参数
    if step % 50 == 0:
        acc = (logits.argmax(1) == y).float().mean().item()
        print(step, round(loss.item(), 3), round(acc, 3))

在一台普通 CPU 上,这段代码大约 2 秒跑完。损失通常从 0.7 附近降到 0.1 以下,准确率升到 95% 以上;具体数字随随机种子波动。如果损失不降,先检查标签和输入是否对齐,再检查学习率是不是大了 10 倍——这两类错误比「网络不够深」常见得多。
