第 04 章 · 核心

多层网络

一条直线分不开四个点。加一层隐藏层,为什么边界就能弯?

读前第 01 章的加权和与激活函数(1.2、1.4),第 02 章的矩阵乘向量(2.2),第 03 章的损失、导数、梯度下降、链式法则与局部极小(3.1–3.6)。可跳过4.3、4.6 的代码块和 4.5 的参数量表;跳过不影响主线。

只有一层权重的网络,能做的事只有一件:在输入空间里切一刀。异或(XOR)只用四个点,就证明了这一刀不够用。本章回答三个问题:为什么必须加隐藏层(hidden layer),为什么隐藏层后面必须跟非线性激活函数(activation function),以及「更深」和「更宽」各自买到了什么。

4.1四个点推翻一条直线

异或是最小的非线性分类问题。两个输入各取 0 或 1,相同则输出 0,不同则输出 1。把四种组合列出来,只有四行:

x1x2异或输出 y在平面上的位置
000左下
011左上
101右下
110右上

把四个样本画成平面上的点:两个 1 在一条对角线上,两个 0 在另一条对角线上。任何线性分类器(linear classifier)的决策边界(decision boundary)都是一条直线,方程是:

w1x1 + w2x2 + b = 0

要分对四个点,这条直线的两侧必须满足四个不等式。被判为 0 的两个点要求函数值小于 0:

(0,0): b < 0     (1,1): w1 + w2 + b < 0

被判为 1 的两个点要求函数值大于 0:

(0,1): w2 + b > 0     (1,0): w1 + b > 0

把前两个不等式相加,得到 w1 + w2 + 2b < 0;把后两个相加,得到同一个式子 > 0。一个数不可能同时小于 0 又大于 0,所以无论怎么选 w1、w2、b,都不存在这样一条直线。这不是训练不够久,而是几何上无解。

1958 年 Rosenblatt 提出的感知机(perceptron)就是这样一个线性分类器。1969 年 Minsky 和 Papert 在《Perceptrons》里用上面这套论证指出单层感知机连异或都做不了,这本书让神经网络研究冷了十几年。需要说清的是:他们证明的是「单层不够」,并没有证明「多层不可训练」。多层网络当时缺的是一个训练算法,这个算法要等到 1986 年反向传播(backpropagation)被重新发现和推广。这两件事后来经常被混为一谈。

4.2隐藏层把平面折起来

多层感知机(multilayer perceptron, MLP)在输入和输出之间插入一层或多层隐藏单元。一个两层网络写成:

h = σ(W1x + b1)     y = softmax(W2h + b2)

softmax 把一组得分压缩成和为 1 的概率,第 6 章会给出完整定义,这里先把它当成「挑最大的那个」。

第一个式子把二维输入送到 H 维的隐藏空间,第二个式子在这个新空间里画一个平面。关键在于:把高维空间里的平面映射回原来的二维平面,得到的不是直线,而是一条弯折的曲线。隐藏层做的事情不是「再切一刀」,而是先把数据搬到一个新坐标系里,让原本纠缠的两类变得可以用一刀切开。这就是表示学习(representation learning)最朴素的样子。

最常用的激活函数是修正线性单元(ReLU),定义只有一个折点:

ReLU(z) = max(0, z)

对输入 x 来说,一个隐藏单元算的是 ReLU(w·x + b):在直线 w·x + b = 0 的一侧,它输出 0;在另一侧,它输出一个随距离线性增长的数。一个隐藏单元就是一条直线加一个折点;H 个隐藏单元给出 H 条直线,H 个折点。输出层把这些折点按权重加起来,决策边界就变成了由若干直线段拼成的折线。折点越多,能围出来的形状越复杂。

异或可以只用两个隐藏单元精确构造。设 h1 计算「或」,h2 计算「与非」,输出层对两者做「与」,其中阈值激活就是阶跃函数(step function),输入的加权和越过阈值时输出 1,h2 取相反的一侧:

x1x2h1 = ORh2 = NAND输出 = AND(h1, h2)
00010
01111
10111
11100

看第三、四行:两个输入不同时,「或」为 1 而「与非」也为 1,「与」把它们同时保留,输出 1;两个输入都为 1 时,「与非」被压到 0,「与」于是输出 0。两条直线完成了四个点,一条直线永远做不到。取阈值 0,一组可用权重是 h1 = step(x1 + x2 − 0.5),h2 = step(−x1 − x2 + 1.5),输出 = step(h1 + h2 − 1.5)。ReLU 可以看作阈值激活的折线版本,它不能精确输出 0/1,但只要把权重放大,折线可以任意接近阶跃函数。

下面的演示把这个过程摊开。左边是决策边界,右边是训练损失。滑块控制隐藏神经元数量,把它拖到 0,网络就退化成 4.1 节那个线性分类器,边界无论如何训练都是一条直线。

交互隐藏层如何把直线掰弯0 个神经元 = 纯线性
0.693训练交叉熵损失
76%训练准确率
42参数量
演示打开时已经用较低学习率预训练了 12 步。拖动滑块会换一个同规模的网络重新预热;点「开始训练」再跑 500 步。把滑块拖到 0,观察损失为什么停在 0.693 附近。

0.693 不是巧合:它是 ln 2,也就是二分类完全靠猜时的交叉熵(cross-entropy)。0 个隐藏神经元时,损失稳定在这个值附近,训练准确率在 50% 到 76% 之间:一条直线最多只能把四个象限中的一个单独判对,不可能同时照顾到两个对角区域。1 个或 2 个隐藏神经元引入了折点,但训练准确率常常停在 76% 左右,折点位置被梯度下降卡住了。理论上两个阈值单元就能精确构造异或,可 ReLU 加随机梯度并不会自动找到那组权重,这是「能表示」和「能学到」之间的第一处裂缝,4.4 节会展开。加到 4 个以上,网络通常能在 500 步内把训练准确率推到 100%;继续加到 32 个,边界更碎、更贴合训练点,但准确率不会超过 100%,多出来的容量没有额外收益。

把隐藏层设为 0 个神经元,训练损失为什么停在 0.69 附近?

4.3没有激活函数,十层等于一层

把隐藏层的 σ 去掉,网络就只剩矩阵乘法和加法。每层做的都是仿射变换(affine transformation):先线性变换,再平移。两层叠起来:

y = W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2)

右边括号里仍然是一个矩阵和一个向量,记作 W 和 b。于是两层等价于一层。这个结论可以一路乘下去:十层仿射变换的复合是一个仿射变换,一百层也是。偏置救不了它,因为偏置本身也在仿射变换里被吸收。换句话说,没有非线性时,深度是假的:参数变多了,表达能力没有变,决策边界仍然是一个超平面。

用五行 numpy 可以数值验证这件事,不需要相信推导:

python
import numpy as np
rng = np.random.default_rng(0)

x  = rng.normal(size=2)
W1, b1 = rng.normal(size=(5, 2)), rng.normal(size=5)
W2, b2 = rng.normal(size=(3, 5)), rng.normal(size=3)

deep = W2 @ (W1 @ x + b1) + b2          # 两层,无激活
flat = (W2 @ W1) @ x + (W2 @ b1 + b2)   # 一层
print(np.allclose(deep, flat))          # True

这也是 PyTorch 里最常见的低级错误:连续写两个 nn.Linear,中间忘了加 nn.ReLU(),第二个线性层等于白加。线性激活函数(identity)同理。判断标准很简单:如果一层里没有非线性,它对函数类的扩张贡献为零。

把 5 个 nn.Linear 直接串联,中间不加任何激活函数,这个网络等价于什么?

4.4万能近似定理:它说了什么,没说什么

万能近似定理(universal approximation theorem)是 1989 年 Cybenko 证明的结论,后来 Hornik 在 1991 年把它推广到一大类激活函数,包括 ReLU。它给出一个让人安心的保证:只要允许隐藏层足够宽,一个只有一层隐藏层的网络可以逼近任意连续函数,误差要多小有多小。写成式子,对紧集(有界闭集,compact set) K 上的任意连续函数 f 和任意 ε > 0,存在宽度 N 和一组参数,使得(其中 sup 是上确界(supremum),即最小的上界):

supx∈K |f(x) − g(x)| < ε

这句话经常被读成「一层网络什么都能做」。它确实说了这件事,但只说了这一件事。定理里的每一个字都值得拆开看:存在性,不是构造性;宽度 N 可以任意大,没有上限;函数 f 必须连续,定义域必须是有界闭集;定理完全不提怎么找到那组参数,也不提需要多少数据。

能表示,不等于能学到,更不等于能泛化

把这三件事分开,是理解深度学习的第一个关口:

  • 能表示(representation):存在一组权重让误差小于 ε。定理保证的是这个。但所需宽度可能大到荒谬:构造一个含 220 ≈ 104 万个锯齿的函数,两层网络可能需要百万级隐藏单元;而 20 层、每层 2 个单元的网络就能精确搭出它。参数效率的差距是指数级的,不是常数倍。
  • 能学到(optimization):梯度下降能不能在有限步内走到那组权重。神经网络的损失函数是非凸的,有大量局部极小和鞍点;定理对优化过程一言不发。实际能不能训出来,取决于初始化、学习率、批大小、归一化,以及架构本身。
  • 能泛化(generalization):在没见过的数据上是否还准。定理讨论的是在一个已知函数上的逼近,而真实任务里你只有几百到几百万个带噪样本。一个能完美拟合训练集的宽网络,可能只是把噪声背了下来。泛化取决于数据量、正则化和归纳偏置(inductive bias),与万能近似定理无关。
常见误解:万能近似定理说明一层就够,所以深度网络是多余的

定理回答的是「存不存在一个足够宽的浅网络」,不是「这个浅网络好不好训、省不省参数、泛不泛化」。对有些函数,浅网络需要指数级宽度,深网络只要多项式级;对图像、语音、语言这类有层次结构的任务,深层网络能复用低层特征,浅层网络只能把每个组合重新学一遍。定理是存在性证明,不是架构推荐。

4.5深度与宽度:各自买到了什么

宽度是一层里并排的神经元数量。一个有 H 个 ReLU 单元的隐藏层,在输入平面上放下 H 条直线,决策边界最多由 H 段折线组成。加宽买到的是「同一层里更多的切法」:参数按 H 线性增长,训练信号只需穿过一层非线性,优化相对容易。

深度是堆叠的层数。每多一层,就对上层的输出再做一次折纸:上一层的每个线性区域会被下一层继续细分。已经有严格结论:一维输入、每层 2 个 ReLU 的网络,层数每增加 1,折线拐点数最多翻一倍;10 层可以造出 1024 段折线,而单层要做到同样细腻需要上千个神经元。深度买到的是「组合」:低层学边缘,中层学部件,高层学物体,同一组低层特征被上层反复复用。

深度不是免费午餐。反向传播把梯度从输出层一路乘回输入层,每穿过一层都要乘一个局部导数矩阵(雅可比矩阵,第 5 章正式定义);层数一多,梯度的模长容易指数级缩小或放大,也就是梯度消失(vanishing gradient)和梯度爆炸(exploding gradient)。原因很直接:总梯度是这些矩阵的连乘,每层的缩放都会累积。假设每层平均把梯度乘上 0.5,穿过 10 层就只剩 0.510 ≈ 0.001;反过来,如果每层平均乘 1.5,10 层后是 1.510 ≈ 58 倍,30 层后超过 19 万倍。矩阵连乘还要看方向,但在最大特征值的方向上,梯度就按这个速度缩小或放大。2015 年的残差连接(residual connection)让信号可以跳过一层直接相加,才让 100 层以上的网络稳定训练;层归一化(layer normalization)和更仔细的初始化解决的是同一类问题。宽度没有这个烦恼,代价是参数多、单层表达仍然受限。

把参数量算清楚,取舍会变得具体。下表全部按「输入 2 维、输出 2 类」计算,每层参数 = 输入数 × 输出数 + 输出数:

结构参数量特点
2 → 256 → 21,282宽而浅,好训,边界最多 256 段
2 → 64 → 64 → 24,482两层非线性,够用于多数表格任务
2 → 64 × 5 层 → 216,962表达更强,也更难训,需要归一化
768 → 3072 → 7684,722,432Transformer 的一个前馈块(feed-forward network, FFN),宽度是模型维度的 4 倍

选择时有几条可操作的规则。数据量小、特征已经手工整理好,用 1 到 2 层、每层 64 到 256 个单元,先确认它能过拟合(overfitting)一个小批量;图像、语音、文本这类有层次结构的信号,深度通常比宽度更划算,10 到 100 层是常见区间;在固定参数预算下,加深往往比加宽更省参数,但优化难度上升,所以现代网络一边加深,一边用残差和归一化把可训练性买回来。

一个实用的判断顺序

训练损失降不到接近 0,说明容量或优化不够:先加宽,再加层,同时检查学习率和激活函数。训练损失很低但测试损失很高,说明是泛化问题:加数据、加正则、早停,继续加宽只会让过拟合更严重。两种情况的方向相反,不要用同一个动作处理。

螺旋数据是异或的多类版本:三条臂从中心向外旋开,任意一条直线都切不开。下面的两个模型在同一份数据上预训练了相同的 120 步,一个只有输出层,一个有 24 × 24 的两层隐藏单元。点「继续训练」,看两种边界如何分道扬镳。

两边共享同一批采样和同样的步数。1 层的边界永远是由几条直线拼成的扇形;3 层会逐渐把三条臂分别包住。多点几次「继续训练」,看准确率各自的平台上限。

浅层模型的准确率会停在一个明显的平台上:三条臂是旋转对称的,任何直线划分都只能覆盖其中一部分,测试准确率通常在 30% 到 45% 之间(三分类瞎猜是 33%)。深层模型在同一步数下可能只领先一点点,继续训练后能到 70% 到 85%。这个差距不是「参数更多」带来的:1 层模型 9 个参数,3 层模型 747 个参数,放在现代网络里都微不足道;差距来自组合:第一层把平面切成若干块,第二层把这些块重新拼成弧形,输出层再按弧线分类。

4.6用 PyTorch 复现异或

下面这段代码可以直接运行。它训练一个 2 → 8 → 2 的网络,参数量 42,在四个点上跑 1000 步。把 nn.ReLU() 那一行删掉,网络就退化成线性分类器,准确率会掉到 75%,和 4.1 节的无解证明对上。

python
import torch
import torch.nn as nn

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([0, 1, 1, 0])

net = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),                 # 删掉这一行,网络退化成线性分类器
    nn.Linear(8, 2),
)
opt = torch.optim.Adam(net.parameters(), lr=0.05)
lossf = nn.CrossEntropyLoss()

for step in range(1000):
    opt.zero_grad()
    loss = lossf(net(X), y)
    loss.backward()
    opt.step()

print(net(X).argmax(dim=1).tolist())              # [0, 1, 1, 0]
print(round(loss.item(), 4))                       # 通常小于 0.01
print(sum(p.numel() for p in net.parameters()))    # 42

把这段代码和本章的演示对照,你会发现三件事是同一件事的不同尺度:演示里 0 个隐藏神经元对应删掉 ReLU 的线性模型;演示里 2 个神经元对应代码里把 8 改成 2,依然能收敛;演示里 32 个神经元对应把 8 改成 32,参数量从 42 涨到 162,测试准确率却不再提高。容量超过任务所需之后,多出来的参数只是在记住训练点的位置。

本章的结论可以压缩成四句。第一,线性模型的边界是超平面,异或是它无法跨越的最小反例。第二,隐藏层把输入搬到新空间,输出层在新空间里切一刀,搬回来就是一条弯折的边界。第三,隐藏层后面必须有非线性,否则所有层会合并成一层。第四,万能近似定理只保证「存在」,深度和宽度的选择要同时考虑可训练性、参数效率和数据量。下一章拆开反向传播,看那条把误差送回每一层的链式法则到底怎么算。
