生成模型

学会数据本身的形状,再从噪声里造出没见过的新样本。

读前第 4 章多层网络、第 5 章反向传播、第 6 章训练循环(会写一次前向与一次反向即可);E 与 σ 见附录 A.6。本章不依赖第 10 章。可跳过11.6 末尾的 PyTorch 代码块和“反向采样到底怎么走”折叠框,跳过不影响主线。

前十章的网络都在做同一件事:给定输入,算出一个输出。这一章换一个问题——没有输入时,网络能不能自己造出一张合理的图?你会训练一个自编码器,亲眼看到潜空间里的结构;再训练一个微型扩散模型,看噪声怎样一步步退成轮廓。

11.1判别与生成:两条相反的路

判别式模型(discriminative model)学的是条件概率 p(y|x):给你一张 28×28 的手写数字图,它在 10 个类别上给出概率。它不需要知道“一张数字图长什么样”,只需要在 784 维像素空间里找到一块能把类别分开的区域。生成式模型(generative model)学的是数据本身的分布 p(x),或者输入与输出的联合分布 p(x,y)。学会之后,你可以从 p(x) 里抽样,得到一张训练集里不存在、但看起来仍属于同一分布的新图。

两件事的难度并不对称。28×28 的图有 784 个像素,即使每个像素只取 0 或 1,可能的图像也有 2^784 ≈ 10^236 种。真实的手写数字只占其中极薄的一片。判别模型只要把这一片和外面分开;生成模型必须给这一片一个概率,并保证采样落回去。本章的四条路线,就是四种逼近这片分布的办法。

核心区别判别模型回答“这像不像猫”,生成模型回答“给我一只猫”。前者只需要一个分数,后者需要一个能反复抽样的分布。

11.2自编码器:压缩再还原

自编码器(autoencoder, AE)是最直白的生成尝试。它由两部分组成:编码器(encoder)把 784 维的图压成一个很短的向量 z,解码器(decoder)再把 z 还原成 784 维的图。训练目标只有一个——让还原出的图尽量接近原图:

LAE = ‖ x − g(f(x)) ‖2

f 是编码器、g 是解码器(encoder/decoder)。逐像素算差值、平方、再求和:重建图越接近原图,这个数越小。

中间那个 z 叫潜变量(latent variable),所有可能的 z 组成的空间叫潜空间(latent space)。当 z 只有 2 维时,网络被迫做一件有意思的事:它必须把“哪些像素总是一起亮”的规律塞进两个数里。于是潜空间不再是随机的坐标纸,相似图片的编码会聚在一起;沿着某个方向移动 z,解码出的图会连续地变形,而不是跳变。

具体到下面的演示:输入是 12×12=144 维的程序生成图形,编码器 144→40→2,解码器 2→40→144,一共 11,906 个参数,加载时先在 500 张图形上热身 60 步(约 0.4 秒),之后在后台继续训练。图形本身由两个旋钮生成:形状指数从 2 到 8(2 是圆,8 接近方),半径从 3.0 到 4.8 个像素;图形画成空心轮廓,不是实心色块。数据真正只有 2 个自由度,2 维潜空间刚好装得下。

鼠标在网格上移动会选中对应样本;拖动两根滑块,看图形连续变形。训练在后台继续,网格会随权重变化。右边的大图是当前坐标的解码结果。

你看到的网格,每一格都是解码器对一个潜变量坐标的输出,不是预先画好的图。网格的不同区域对应不同的形状和大小:有的格子接近圆,有的接近圆角方;沿着某个方向移动,轮廓连续地变方、变大。说明编码器确实把数据的两个自由度安排进了两个坐标轴——虽然轴的方向被网络自己旋转过,不一定和你的直觉对齐。把鼠标移到某一格,两根滑块会跳到那个坐标;拖动滑块,图形连续变化。这就是“潜空间有结构”的具体含义:相邻的 z 解码出相似的图,方向对应着可解释的变化。

但自编码器有一个致命缺陷:它只保证在训练样本的编码附近能还原,对潜空间的其它位置没有任何约束。你在网格边缘看到的模糊形状或整块色块,就是证据。想从标准正态分布(standard normal,均值 0、方差 1 的钟形分布)里随机抽一个 z 解码?大概率抽到训练时从未出现过的区域,输出既不像圆也不像方。自编码器给了你一个压缩映射,却没有给你一个可以采样的概率分布。

11.3VAE:给潜空间装上概率

变分自编码器(variational autoencoder, VAE)补上的正是这一点。编码器不再输出一个点,而是输出两个向量:均值 μ 和方差 σ²(σ 是标准差,standard deviation)。训练时先从这个正态分布里抽一个 z,再送去解码:

z = μ + σ ⊙ ε,   ε ~ N(0, I)

意思是:在编码器给出的均值附近,按它给出的标准差撒一个随机点,再把这个点送去解码。

ε 从标准正态分布采样,⊙ 是逐元素相乘。这个写法叫重参数化技巧(reparameterization trick):随机性被挪到不参与训练的 ε 上,μ 和 σ 仍然是网络的可导输出,梯度可以穿过采样这一步回传。没有它,采样是一个不可导的随机操作,反向传播在这里就断了。

损失函数由两项组成(重建项写成均方误差的简化版):

LVAE = ‖ x − g(z) ‖2 + β · KL( N(μ, σ2) ‖ N(0, I) )

两项相加:既要还原得像,又要把编码分布拉向标准正态。

第一项要求重建准确,第二项是 KL 散度(Kullback–Leibler divergence),衡量编码器给出的分布离标准正态有多远。把每个样本的后验(posterior,见过数据后对 z 的推断)都往 N(0,I) 拉,效果是整个潜空间被铺成一片连续、没有空洞的概率云:任意抽一个 z,解码器都在它附近见过训练样本。

β 控制两项的拉扯。β 太小,KL 项形同虚设,VAE 退化成普通自编码器:重建很清楚,但潜空间又出现空洞,采样质量下降。β 太大,编码器干脆放弃区分样本,把所有输入都映射到同一小片区域,解码器只能输出所有图片的平均值。常见取值在 0.5 到 4 之间;β-VAE 的论文用 β=4 换取更解耦的潜变量,代价是重建更模糊。原始 VAE 在 MNIST 上用 784→400→20 的架构,约 64.5 万个参数,20 维潜空间已经能生成可辨认的数字。本章的 2 维版本不是为了效果好,而是为了让你用眼睛看见分布。

常见误解VAE 生成的图模糊,是因为网络太小或者训练不够。把解码器换成几十层的 ResNet,模糊依旧。原因在目标函数:像素级重建误差(尤其均方误差)对不确定的细节取平均,模型宁可输出一张“平均的脸”,也不愿赌一个清晰的细节;KL 项又要求潜变量覆盖一整片区域,进一步鼓励平滑。想要锐利,得换损失(感知损失、对抗损失)或换模型(GAN、扩散),而不是单纯加层数。

11.4GAN:让两个网络互相为难

生成对抗网络(generative adversarial network, GAN)放弃了“先压缩再还原”的路线。它直接训练一个从噪声到数据的映射:生成器(generator)G 接收 100 维随机噪声 z,输出一张图;判别器(discriminator)D 接收一张图,输出它是真实样本的概率。两个网络轮流训练,目标相反:

minG maxD Ex~pdata[log D(x)] + Ez~p(z)[log(1 − D(G(z)))]

E[·] 是期望,按概率加权平均(expectation)。读法是:D 想把这个值调大(真实图判 1、生成图判 0),G 想把它调小(让 D 把生成图判成 1)。训练时交替:固定 G,用真实图和生成图训练 D 若干步;再固定 D,把 G 的输出贴上“真”的标签训练 G。理论上,当 G 的分布完全等于数据分布时,D 对任何输入都只能输出 0.5,双方达到纳什均衡(Nash equilibrium)。

实际训练远没有这么优雅。D 太强,G 的梯度会饱和到接近 0,生成器学不到东西;D 太弱,G 拿到的是噪声般的信号,生成质量来回震荡。这就是 GAN 需要精心调学习率、更新比例、梯度惩罚的原因。2014 年原始 GAN 用多层感知机在 MNIST 上生成模糊数字;2015 年 DCGAN 用卷积把 64×64 的卧室图做得像样;StyleGAN2 在 70,000 张 1024×1024 人脸上训练,生成一张图只需要一次前向,约 0.05 秒。速度是 GAN 至今最大的优势。

模式崩塌(mode collapse)是 GAN 最典型的失败。G 发现生成某一类样本最容易骗过当前的 D,就把所有噪声都映射到那一类,彻底放弃其它模式。比如在 10 类手写数字上训练,生成器可能只产出“1”和“7”,而且每个都长得差不多。D 学会识破后,G 又切换到另一个模式继续塌,训练在少数几个模式之间来回跳。根因是 GAN 的目标只要求“骗过 D”,没有一项损失明确要求“覆盖数据里的每一个模式”;这不是过拟合,也不是训练集太小。

训练 GAN 时,生成器开始反复输出几乎一样的“7”,判别器对此的准确率很高。最可能发生了什么?

11.5扩散模型:先学加噪,再学一步步去噪

扩散模型(diffusion model)换了一个更笨、但更稳的办法:不直接学 p(x),而是学“怎样把噪声一步步变回数据”。它包含两个过程。

前向过程(forward process)是一串固定的加噪步骤:每一步给图加一点高斯噪声(Gaussian noise,均值 0 的正态随机扰动),共 T 步。取 T=1000、β 从 10⁻⁴ 线性增到 0.02 时,最后一步的图和纯噪声在视觉上无法区分。关键公式是它的闭式解——你可以一步跳到任意 t,不必真的循环 1000 次:

xt = √ᾱt · x0 + √(1 − ᾱt) · ε,   ε ~ N(0, I),   ᾱt = ∏s=1t(1 − βs)

x₀ 是干净图,x_t 是第 t 步的图。ᾱ_t 是到 t 步为止累计保留的信号系数:t=0 时 ᾱ=1,只剩原图;t=T 时 ᾱ≈0,只剩噪声。这个式子说明,任意时刻的图都是原图和标准噪声的一个加权混合。

反向过程(reverse process)训练一个网络来猜:给定 x_t 和 t,这一步混进去的噪声是什么?记作 ε_θ(x_t, t)。损失就是预测噪声和真实噪声的均方误差:

Ldiff = E[ ‖ ε − εθ( √ᾱt x0 + √(1−ᾱt) ε, t ) ‖2 ]

注意这个损失里没有对抗、没有判别器、没有需要平衡的两个网络,只有一次回归。这是扩散模型训练稳定的根本原因:每一步都是一个普通的监督学习问题,梯度不会因为对手变强而消失。采样时从纯噪声 x_T ~ N(0,I) 出发,让网络估计并减掉噪声,重复 T 步。原始 DDPM(Denoising Diffusion Probabilistic Models)要 1000 次前向,DDIM(Denoising Diffusion Implicit Models)可以把同样的训练目标压到 20 到 50 步;下面的演示用 48 步。

演示训练一个 16×16 输入、64 个隐藏单元、33,216 个参数的小去噪器,在 320 张环状图形上先热身 60 步(约 0.8 秒),之后在后台继续训练。网络直接预测 x₀(与预测噪声等价,两者只差一个由 ᾱ_t 决定的线性变换),所以 DDIM 更新用 x̂₀ 写最直观;为了让 48 步采样稳定,演示用的是余弦噪声调度(cosine schedule),不是上面那组线性 β。左边拖动 t 看同一张图被噪声吞没;右边从纯噪声开始逐步采样,看环的轮廓从颗粒里浮出来。

为什么扩散成了主流?四个原因。第一,训练目标是回归,不会像 GAN 那样崩,超参数宽容得多。第二,每个训练样本都以一定概率被重建,模型没有动机放弃某些模式,模式覆盖明显更好。第三,样本质量:在 ImageNet 256×256 上,扩散模型的 FID(Fréchet Inception Distance)已经低于最好的 GAN。第四,条件化统一:文本、类别、深度图、遮罩都可以作为额外输入塞进 ε_θ,同一套框架通吃。

代价是采样慢。GAN 生成一张图只要 1 次前向,扩散要 20 到 1000 次。后来的潜扩散(latent diffusion)解决了大部分成本:先用自编码器把 512×512×3=786,432 维的图压到 64×64×4=16,384 维的潜空间,再在潜空间里做扩散,计算量降到约 1/48。Stable Diffusion 的 U-Net 约 8.6 亿参数,训练数据 LAION-5B 包含 58.5 亿个图文对;它生成的 512×512 图,实际上是在 64×64 的潜变量上采样出来的。

下面是把扩散训练写成 PyTorch 的样子。图像被拉成一维向量,去噪器换成三层 MLP;真实实现把 MLP 换成 U-Net,训练目标一字不改。

python
import itertools, torch, torch.nn as nn

T = 1000
beta = torch.linspace(1e-4, 0.02, T)          # 每步加多少噪声
abar = torch.cumprod(1.0 - beta, dim=0)       # ᾱ_t: 到第 t 步累计保留的信号系数

class Denoiser(nn.Module):
    def __init__(self, size=16, hidden=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(size * size + 1, hidden), nn.SiLU(),
            nn.Linear(hidden, hidden), nn.SiLU(),
            nn.Linear(hidden, size * size),
        )
    def forward(self, x, t):                   # x: [B, 256], t: [B]
        return self.net(torch.cat([x, t[:, None]], dim=1))

model = Denoiser()
opt = torch.optim.Adam(model.parameters(), lr=2e-3)

for step, (x0, _) in zip(range(20000), itertools.cycle(loader)):
    x0 = x0.flatten(1)                          # 干净图: [B, 256]
    t = torch.randint(0, T, (x0.shape[0],))
    eps = torch.randn_like(x0)
    ab = abar[t][:, None]
    xt = ab.sqrt() * x0 + (1 - ab).sqrt() * eps
    pred = model(xt, t.float() / T)
    loss = ((eps - pred) ** 2).mean()
    opt.zero_grad()
    loss.backward()
    opt.step()
反向采样到底怎么走

训练好 ε_θ 之后,DDIM 的每一步是:

xt−1 = √ᾱt−1 · x̂0 + √(1 − ᾱt−1) · ε̂

其中 x̂₀ = (x_t − √(1−ᾱ_t) · ε_θ(x_t,t)) / √(ᾱ_t),ε̂ = (x_t − √(ᾱ_t) · x̂₀) / √(1−ᾱ_t)。第一项把预测出的干净图按比例放回去,第二项补上剩余噪声。每一步都重复这个动作,噪声的方差逐级减小,轮廓就显现出来。
