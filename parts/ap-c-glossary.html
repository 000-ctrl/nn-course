读前前 14 章的概念,至少第 03 章的梯度与损失、第 05 章的反向传播、第 06 章的损失/学习率/epoch——C.2 的验收标准与 C.3 的代码直接用到它们。可跳过C.1 的搜索演示、C.2 的打卡演示、C.3 的整段 PyTorch 代码块可跳过,不影响两条路线的选择。

这一章不引入新模型。它做两件事:把全书反复出现的 50 个词压成一页可搜索的速查表,再给出两条带验收标准的学习路线。术语按「数据—结构—训练—评估—架构」的顺序排列,不是字母序;路线按「能做出什么」验收,不是按「读了哪几页」。学完前 14 章之后,这一页应该成为你回头查得最频繁的一页。

C.1一张能搜的术语表

同一个概念在书里通常有三个名字:中文译名、英文原名、数学符号。损失函数(loss function)在公式里写 L,在 PyTorch 里叫 loss_fn;学习率(learning rate)写作 η,在代码里叫 lr;批(batch)在论文里也写成 mini-batch。这三个名字指同一件事,但搜索框一次只能命中其中一种写法。术语卡片把三种写法放在一起,所以输入「交叉熵」「cross」或者「4.605」都能找到它。

每条解释只写一句话,重点不是词典义,而是它在网络里具体干什么。例如「偏置」(bias)不是性格上的偏见,而是加权和之后再加的常数,作用是把激活阈值整体平移;「嵌入」(embedding)不是把东西塞进去,而是一张可学习的查表,词表 50,000、维度 768 时这张表有 3,840 万个参数。「卷积」(convolution)也不是数学课上的积分,而是同一组小权重在图像上滑动、在每个位置做一次点积。

为什么一定要给英文:框架的报错、论文的图注、模型的配置文件都用英文。你搜「Expected all tensors to be on the same device」,关键词是 tensor,不是「张量」;你读 Transformer 论文,图里写的是 query、key、value,不是「查询、键、值」。记住英文名,等于拿到一把能开三扇门的钥匙。这张表里 50 条术语覆盖了本书从单个神经元到大语言模型的全部关键节点,每条都至少在前面的章节里出现过一次。

用法:先搜,再背

术语不要按顺序背。遇到一个词,先搜一次,看它一句话在干什么,再回到上下文。同一个词在不同章节出现三次,你自然会记住;一次背 50 条,三天后通常只剩前 5 条。真正需要背的是三组对照:weight 与 bias、loss 与 metric、epoch 与 batch。

没有匹配的术语。试试更短的关键词,或者只输入英文的前几个字母,例如把 gradient 缩成 grad。

C.2四周版与三个月版

路线不是课程表,是验收清单。每条任务都写成可以判定的结果:不是「理解反向传播(backpropagation)」,而是「手推一个 2→3→1 网络(2 个输入、3 个隐藏、1 个输出)的一轮反向,解析梯度(analytic gradient,按公式直接算出)与数值微分(numerical differentiation,用差分近似)的最大误差小于 1e-6(即 0.000001)」。能判定,才知道自己走到哪;不能判定,「学过了」只是一种感觉。

四周冲刺版面向每天能挤出 1.5 到 2 小时的人,总计约 40 到 50 小时,16 个任务。第 1 周只碰一个神经元和线性回归,把损失从 2.4 压到 0.02;第 2 周写完整训练循环,并故意制造一次学习率过大导致的发散;第 3 周进 MNIST 和卷积(convolution),目标测试集 97% 与 15 万参数以内;第 4 周做字符级循环网络(recurrent neural network, RNN)和一个 30 行的推理脚本。终点是:给你一份表格数据或 28×28 的图片,你能独立跑出一个可信的 baseline。

三个月系统版面向每周能投入 6 到 8 小时的人,总计约 72 到 96 小时,24 个任务。它把四周版压扁的部分展开:第 1 个月补数学与训练工程,第 2 个月做视觉,第 3 个月做序列、注意力和 mini GPT,最后一周复现一篇小论文的表格。终点不是「学过」,而是「能复现」。

顺序不能倒。很多人一上来就读 Transformer,结果卡在三件更基础的事上:数据怎么归一化、损失为什么不降、验证集(validation set)为什么比训练集差 20 个百分点。注意力本身只有一行公式,难的是它周围的训练管线。先把一个 101,770 个参数的 MLP 训明白,再去看 1.75 亿参数的模型,你看到的才是结构,不是魔法。

C.3数据集与五个练手项目

数据集选错,后面的调参全是白费。下面 7 个数据集都能在 10 分钟内下载完,规模从 150 行到 110 万字符,覆盖回归、分类、文本和序列。先用小数据把管线跑通,再换大数据,是唯一不会把自己绕晕的顺序。

数据集规模输入适合练什么
Iris150 条,3 类4 个特征第一个分类器、决策边界
California housing20,640 行8 个特征回归、归一化、RMSE
MNIST70,000 张(60k/10k)28×28 灰度多分类、MLP 基线
Fashion-MNIST70,000 张28×28 灰度同一套代码换数据、调容量
CIFAR-1060,000 张(50k/10k)32×32×3 彩色卷积、数据增强

Tiny Shakespeare1,115,394 字符65 个不同字符字符级语言模型、生成

五个项目,按难度排。每个都给了可验收的数字,做不到就回头补对应章节,不要直接换更花哨的模型。

  1. 房价回归。California housing,20,640 行、8 个特征,网络 8→16→1,目标验证集 RMSE 低于 0.6(标签单位是 10 万美元)。这一项练的是输入归一化、均方误差和早停。
  2. MNIST 分类。60,000 张训练图、10,000 张测试图,784→128→10 的 MLP 有 101,770 个参数,批大小 64 时一轮是 938 次参数更新,3 轮后测试准确率应到 97% 以上。
  3. CIFAR-10 卷积。50,000 张 32×32 彩色图、10 类。一个约 10.6 万参数的小 CNN,配合随机裁剪与水平翻转,测试准确率应到 72% 到 78%。做不到 72%,先检查归一化和学习率,而不是急着加深网络。
  4. 字符级语言模型。Tiny Shakespeare 共 1,115,394 个字符、65 个不同字符,初始交叉熵是 ln65≈4.17。训练到 1.6 以下后,让模型生成 200 个字符,看它是否学会了空格、换行和人物名的开头。
  5. mini GPT。2 层、4 个注意力头、d_model=128、上下文长度 128,约 43 万参数,在同一份莎士比亚文本上把验证损失压到 2.0 以下。这一项把嵌入、位置编码、注意力和残差连接串成一条线。

下面这段 PyTorch 代码就是项目 2 的完整骨架,复制到本地就能跑。它没有数据增强,也没有学习率调度,故意保持最短:先确认每一步都在干什么,再加技巧。代码里的 784 来自 28×28,10 来自类别数,这两个数字换成别的数据集就不再成立。

python
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

tf = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,)),
])
train_set = datasets.MNIST("data", train=True, download=True, transform=tf)
test_set = datasets.MNIST("data", train=False, transform=tf)
train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
test_loader = DataLoader(test_set, batch_size=256)

model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 128), nn.ReLU(),
    nn.Linear(128, 10),
)
loss_fn = nn.CrossEntropyLoss()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(3):
    model.train()
    for x, y in train_loader:
        opt.zero_grad()
        loss = loss_fn(model(x), y)
        loss.backward()
        opt.step()

    model.eval()
    correct = total = 0
    with torch.no_grad():
        for x, y in test_loader:
            pred = model(x).argmax(1)
            correct += (pred == y).sum().item()
            total += y.size(0)
    print(f"epoch {epoch + 1}: test acc {correct / total:.3f}")

C.4学完之后:能做什么,不该指望什么

学完这本书,你应该能做的事情很具体。拿到一个表格任务,判断它该用回归还是分类;拿到一张图,知道先试 MLP 再试卷积;拿到一段文本,知道循环网络和 Transformer 的取舍。你能估算一个模型的参数量与显存,能读懂损失曲线的三种形状,能在验证集变差时先怀疑过拟合(overfitting),而不是盲目加层。你也能把「训练不动」拆成四个可检查的点:数据、初始化、学习率、梯度。

你已经具备
  • 独立训练 10 万到 100 万参数的小模型,并让测试指标可信
  • 看懂论文里的架构图,把每个箭头对应到一个张量形状
  • 写出训练、验证、保存、加载的完整循环
  • 在单张 24GB 显卡上用 LoRA 微调 7B 级别的开源模型
还不该指望
  • 从零预训练 GPT 级模型:1750 亿参数、约 3.14×1023 次浮点运算,需要上千张加速卡和数百万美元
  • 保证 SOTA:论文数字依赖数据清洗、训练技巧和算力,不是改两行代码就能复现
  • 独立完成生产部署:服务化、监控、回滚、安全对齐是另一套工程
  • 做理论证明:收敛性与泛化(generalization)的理论界属于研究数学,这本书只给直觉
常见误解:损失降到 0.004 就是训练成功

一个 784→512→10 的 MLP 在 MNIST 上训练 30 轮,训练损失可以低到 0.004、训练准确率 99.9%,但如果没做输入归一化、也没加任何正则,测试准确率可能只有 88%。两者差 11.9 个百分点,模型只是记住了 60,000 张训练图。更隐蔽的错误是拿测试集调参:你用它比较了 20 组超参数,它就参与了模型选择,再报它的准确率已经偏乐观。判断模型好坏只看一个数:在从未参与任何决策的测试集上的指标。
