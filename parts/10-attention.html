注意力与 Transformer

让每个词自己决定该回头看哪些词,再把它们的信息加权混合。

读前第 9 章的循环网络、隐藏状态与 9.6「注意力为什么赢了」;softmax 与交叉熵见第 6.2 节;矩阵乘法与转置见第 2 章;反向传播见第 5 章。可跳过10.7 的 PyTorch 代码块、10.4 的正弦公式细节和 10.3 的参数量手算可跳过,不影响 10.1—10.6 的主线

第 9 章的循环网络把全部历史压进一个固定长度的隐藏状态,常见是 512 维。序列一长,第 800 个 token(词元)仍要背着第 1 个 token 的信息,这条链既慢又容易断。注意力(attention)换了个办法:不压缩历史,把每个 token 的向量原样保留,当前 token 按需回去查。Transformer 就是把这种查表动作堆叠 12 到 96 层。

先把第 9 章的循环网络(recurrent neural network, RNN)捡回来。它在每个时间步读入当前输入 xt 和上一步的隐藏状态 ht−1,用同一组权重算出 ht = tanh(Wxxt + Whht−1 + b)。这一步把「看到过的所有东西」压进一个固定长度的向量,常见是 512 维;序列走到第 800 个 token 时,第 1 个 token 的信息必须一路挤过这 800 次压缩,每挤一次都会损失一点,长距离依赖(long-range dependency)的信号就这样衰减下去。注意力要解决的就是这件事:不再强迫历史挤进一个向量,而是把每个位置的向量原样留着,需要时直接回去取。

10.1一次软查表

先想词典。你拿着一个词去查,键完全相等才命中,这是硬查表。注意力是软查表:拿一个查询,和每一个键算相似度,把相似度变成 0 到 1 的权重,再按权重把所有值混合起来。没有相等与不相等,只有权重高低。这个过程叫自注意力(self-attention),因为查询、键、值都来自同一句话。

看两句话。第一句是「小狗追着球跑,它很开心」,第二句是「小狗追着球跑,它滚进了草丛」。两个「它」字形一样,第一句指向小狗,第二句指向球。模型靠什么决定?靠上下文算出的查询向量。同一个词在不同上下文里,查询不同,匹配到的键也不同。

每个 token 的输入向量 x(例如 512 维)会乘上三个不同的学习矩阵,得到三个向量:

查询 query

我现在想找什么。由当前位置的向量算出,相当于检索时输入的关键词。

键 key

每个位置对外张贴的标签。它决定「我这儿有什么信息,值不值得被查」。

值 value

匹配成功后真正交给对方的内容。权重乘的是它,不是键本身。

三个矩阵 W_Q、W_K、W_V 都是训练出来的,没有人手写「代词指向前面最近的名词」这条规则。梯度下降只负责让下一 token 的预测更准,指向关系是它自己学到的副产品。第 1 层的查询只来自词嵌入和位置,还分不清两个「它」;经过几层,每个位置的向量已经混入了前文,后面的层才有能力稳定指向正确的名词。

10.2点积、softmax 与因果掩码

查询和键的相似度用点积(dot product)算:q·k = q₁k₁ + q₂k₂ + … + q₆₄k₆₄。两个向量方向越一致,点积越大;正交时接近 0;方向相反时为负。把所有查询排成矩阵 Q,所有键排成 K,一次矩阵乘法 QKᵀ 就得到每个查询对每个键的分数,形状是 token 数乘 token 数。

具体算一遍。假设某个查询对三个键的原始分数是 2.0、0.5、-1.0。先取指数:e² = 7.389、e⁰·⁵ = 1.649、e⁻¹ = 0.368,和为 9.406。归一化后得到 0.786、0.175、0.039,三个数相加正好为 1。原始分数只差 3.0,取指数后最大和最小差了 20 倍,softmax 会把这种差距进一步放大。

公式里的 √d_k(d_k 是键向量的维度,key dimension)不是装饰。假设 d_k = 64,查询和键的每个分量独立、均值接近 0、方差(数据散布的宽度,variance)约为 1,点积的方差约为 64,标准差(方差的平方根,standard deviation)就是 8,分数常在正负 20 之间摆动。直接送进 softmax,最大的那个会接近 1,其余接近 0,梯度几乎消失。除以 √64 = 8 把标准差拉回 1 附近,softmax 才不会一上来就饱和。

Attention(Q,K,V) = softmax(QKT / √dk) V

读法:先用 Q 和 K 算出每个位置该看谁,softmax 把每一行变成概率,再乘以 V 得到输出。每一行的权重和为 1,输出是同一行所有 value 的加权平均。

解码器还要加因果掩码(causal mask)。位置 5 只能看位置 0 到 5,位置 6 及以后的分数在 softmax 之前被改成负无穷,softmax 之后精确为 0。训练时仍然可以一次算完整个矩阵,因为每个位置看到的上三角已经被挖掉,不会偷看答案。这也是 Transformer 比循环网络快的关键:训练时整句并行,不用等第 5 个 token 算完再算第 6 个。

代价是平方级的计算量。序列长度 n = 1024 时,单层单头要算 1024 × 1024 = 1,048,576 个分数;12 层、12 头就是 1,048,576 × 12 × 12 = 150,994,944 个,约 1.51 亿个。序列翻倍,这个数字变成四倍。

10.3多头:几种看法同时进行

一个头只能输出一种混合。语言里同时存在多种关系:相邻词、主谓、动宾、指代、标点收束。多头注意力(multi-head attention)让模型并行学几套 Q/K/V,每套关注不同的关系。以 d_model = 512、8 个头为例,每个头分到 d_k = d_v = 64 维。8 个 64 维的输出拼回 512 维,再乘一个 W_O 做混合。

参数量算一下。Q、K、V、O 四个 512×512 矩阵,加偏置:4 × (512×512 + 512) = 1,050,624。多头不是把计算量乘 8,而是把 512 维切成 8 份,每份 64 维;总矩阵乘法和一个 512 维单头基本相同。切分让不同子空间独立,不是让模型变宽 8 倍。

头之间确实会分工,但不保证整齐。探测研究里常见到:有的头盯前一个 token,有的头连接主谓,有的头几乎不做事。把一部分头剪掉,某些模型的精度只掉不到 1 个百分点;剩下的头会补位。这说明「每个头专门负责一种语法」是过度整齐的想象,更准确的说法是「多个头提供了多种可用的混合方式,训练会挑有用的用」。

常见误解:注意力权重就是解释

看到某个头把 0.9 的权重给了「小猫」,不等于「小猫」贡献了 90% 的输出。第一,权重乘的是 V,而 V 还要经过 W_O 与其他头混合;第二,不同头可能重复表达同一件事;第三,残差连接和前馈网络也在搬运信息。注意力权重只说明「这个头从哪儿取了多少」,不说明「最终输出为什么是这样」。要谈解释,至少要看多层多头的平均、梯度归因或消融实验。

10.4位置编码:给没有顺序感的模型一个顺序

把一句话的词打乱,自注意力的输出只是跟着打乱,内容不会变,因为 QK 只比较内容,不知道谁在前。没有掩码的编码器里,「狗咬人」和「人咬狗」得到的是同一组向量,只是顺序不同。因果掩码规定了谁能看谁,却仍然没告诉模型两个位置相隔几个 token。

位置编码(positional encoding)解决这件事:给每个位置算一个向量,直接加到词向量上。原版 Transformer 用固定正弦函数:

PE(pos, j) = sin(pos / 10000j/d)(j 为偶数)    PE(pos, j) = cos(pos / 10000j/d)(j 为奇数)

pos 是位置编号,j 是维度编号(直接就是维度下标,不是维度对的编号),d 是向量宽度。偶数维用 sin,奇数维用 cos,同一个位置的不同维度使用不同频率。

频率按几何级数排列。d = 512 时,第 0 维的波长是 2π ≈ 6.28 个位置,每 6 个多 token 转一圈;第 510 维的波长约 6.05 万 个位置,几乎是一条缓慢的斜线。低维负责细粒度位置,高维负责粗粒度位置,拼起来像一套连续的二进制计数。位置向量直接相加,不是拼接,因为两者量级相近,加法不会把语义盖掉。

后来出现三种常见变体。GPT-2 用可学习的绝对位置嵌入,一张 1024×768 的表,共 786,432 个参数;原版 Transformer 用固定正弦;Llama 用旋转位置编码(rotary position embedding, RoPE),把 q、k 按位置旋转一个角度,点积只依赖相对距离。三者都在回答同一个问题:让「相隔几个」进入模型。

10.5一个 block:残差、LayerNorm、前馈

注意力对 V 做的是加权和:权重由输入非线性地决定,但每一层的输出本身仍是本层 value 的线性组合。如果只有注意力,层与层之间又没有逐元素的非线性,整个堆叠仍然只是把 value 线性组合起来——权重会嵌套、随输入变化,但它依然缺少「逐个元素先判断再变换」的能力。Transformer block 在注意力后面加一个前馈网络(feed-forward network, FFN),再给两个子层都套上残差连接(residual connection)和层归一化(layer normalization)。

x = x + Attention(LN(x))
x = x + FFN(LN(x))

这是 Pre-LN 写法:先归一化,再进子层,最后把子层的输出加回原向量。原版论文用 Post-LN,把 LN 放在相加之后;Pre-LN 在深模型里更稳,现代大模型多用它。

层归一化在一个 token 的 512 个特征上算,不是在一个 batch 的同一特征上算。举例:某个 token 的四维向量是 [1, 2, 3, 4],均值 2.5,标准差 1.118,归一化后是 [-1.342, -0.447, 0.447, 1.342],再乘可学习的 γ(缩放,gamma)、加 β(平移,beta)。因为统计量按 token 自己算,batch 大小为 1 也能用,这一点和批归一化(batch normalization)不同。

前馈网络是两层全连接:512 → 2048 → 512,中间用 GELU 激活。参数量 512×2048 + 2048 + 2048×512 + 512 = 2,099,712。它逐 token 独立计算,不交换位置之间的信息;信息交换只发生在注意力里。一个 block 的总参数约为 1,050,624 + 2,099,712 + 2×1,024 = 3,152,384,约 315 万。

残差连接是深度的关键。x + f(x) 给梯度留了一条恒等通道,反向传播时梯度可以直接流过加法,不必穿过每一层的雅可比矩阵。没有残差,96 层的 Transformer 很难训练;有了残差,层数从 6 加到 96 是工程问题,不是原理问题。GPT-2 small 的 d_model = 768、12 层、12 头,每层约 708 万参数,加上 50,257×768 = 38,597,376 的词嵌入和 786,432 个位置参数,总参数 1.24 亿。

10.6tokenizer 与自回归生成

模型不读汉字,只读整数。分词器(tokenizer)把文本切成 token(词元),再给每个 token 一个整数 ID。为什么非要做这一步?因为模型的第一层是一张嵌入(embedding)表,表按整数下标取行,没有下标就取不出向量。GPT-2 的词表(vocabulary)有 50,257 个 token,一个中文字常被切成 1 到 3 个 token;具体怎么切、字节对编码(byte pair encoding,BPE)如何合并片段,第 12 章 12.3 会讲,这里只要记住:文字先变成整数,整数再去查表。

输入的 ID 去查一张 50,257×768 的嵌入(embedding)表,得到 768 维向量;加上位置编码;送进 12 层 block;最后乘输出矩阵,得到 50,257 个未归一化的分数(logits)。softmax 之后,就是下一个 token 的概率分布。

自回归(autoregressive)的意思是:每次根据已经生成的前缀预测下一个 token,把它接回输入,再预测下一个。训练时答案已知,可以把整句右移(整体后挪一格,shift right)一位,一次前向同时算所有位置的损失,这叫教师强制(teacher forcing);推理时没有答案,只能一个一个来。生成 500 个 token 要跑 500 次前向。键值缓存(KV cache)把每层已经算过的 K、V 存下来,新 token 只算自己的 q、k、v,再和缓存拼接。代价是显存:1024 个 token、12 层、12 头、每头 64 维,单条样本的 K 缓存约 18 MB(FP16),V 再加一倍。

温度与采样(简述)

模型输出的是 50,257 个未归一化的分数(logits),要变成一个词,先 softmax 成概率,再从分布里挑。贪心解码(greedy decoding)每次取概率最高的一个,输出稳定但容易重复;按概率随机抽则每次不同。温度(temperature)是插在 softmax 里的一个标量:

pi(T) = exp(zi/T) / Σj exp(zj/T)

Σ 是求和,把各项加起来(sum);z 是 logits,T 是温度。T 小于 1 时分布变尖,高概率的词更容易被选中;T 大于 1 时分布变平,低概率词也有机会;T 趋近 0 时退化为贪心;T 趋近无穷时变成均匀分布。T 不改变模型参数,只改变从 logits 到概率的变换。

用「今天天气真」后面的一组概率(好 42%、不错 23%、热 13%、冷 9%、糟 7%、一般 6%)算一下:T = 0.5 时「好」升到约 67.1%;T = 2 时降到约 28.2%,六个词都变得可能。除了温度,还有 top-k(只留概率最高的 k 个)和 top-p(核采样,nucleus sampling,留累计概率到 p 的最小集合,常用 p = 0.9)。这三个参数只改推理时的取词方式,不改模型权重;第 14 章 14.5 会把它们放回推理服务的完整流程里。

10.7自己写一遍注意力

下面的 PyTorch 代码把上面所有公式落成 40 行。先看形状:q、k、v 的形状都是 [batch, heads, seq, d_k];scores 是 [batch, heads, seq, seq];mask 用 1 表示可见、0 表示遮住。运行前把 d 设成 64、头数设成 4、序列长度设成 16,一次前向在 CPU 上不到 1 毫秒。

python
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

def attention(q, k, v, mask=None):
    # q, k, v: [batch, heads, seq, d_k]
    d_k = q.size(-1)
    scores = q @ k.transpose(-2, -1) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    w = F.softmax(scores, dim=-1)
    return w @ v, w

class Block(nn.Module):
    def __init__(self, d=512, h=8):
        super().__init__()
        self.h = h
        self.ln1 = nn.LayerNorm(d)
        self.qkv = nn.Linear(d, 3 * d)
        self.out = nn.Linear(d, d)
        self.ln2 = nn.LayerNorm(d)
        self.ff = nn.Sequential(
            nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d))

    def forward(self, x, mask=None):
        B, n, d = x.shape
        q, k, v = self.qkv(self.ln1(x)).chunk(3, dim=-1)
        q, k, v = [t.view(B, n, self.h, d // self.h).transpose(1, 2)
                   for t in (q, k, v)]
        a, _ = attention(q, k, v, mask)
        a = a.transpose(1, 2).reshape(B, n, d)
        x = x + self.out(a)
        x = x + self.ff(self.ln2(x))
        return x

这段代码里没有循环网络的时间步,也没有卷积。序列维度 n 只出现在矩阵乘法里,所以同一个 batch 的所有位置能一起算。真正的 GPT 只是把 Block 堆 12 到 96 次,前面加 tokenizer,后面加采样循环;核心就是这几十行。这里的 12 到 96 层说的是一代到三代的稠密(dense)模型:GPT-1 是 12 层、GPT-3 是 96 层,每个 token 都要过全部参数。现代大模型还会叠加混合专家(mixture of experts, MoE):每层放几十个专家,每个 token 只激活其中一两个,总参数量能到几千亿,单次计算却只按激活的那一小部分算。第 14 章会讲 MoE 怎么接进 Block。

一句话记住 Transformer

每个 token 带着自己的查询,去所有 token 的键里找匹配,按匹配度混合它们的信息;顺序靠位置编码,深度靠残差,稳定靠 LayerNorm,非线性靠前馈网络。缺了前馈和残差,它只是一个会看上下文的加权平均器。

训练与推理别混用温度

训练时用教师强制和交叉熵,温度通常不参与;推理时才用温度、top-k、top-p 调风格。评估模型能力时用贪心或 T=1,不要把高温采样的随机性当成模型变聪明或变笨。
