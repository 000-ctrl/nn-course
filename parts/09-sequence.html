第 09 章 · 序列

循环网络

当顺序本身携带信息,网络必须学会记住刚刚看过什么。

读前第 2 章矩阵形状(2.2、2.3)、第 4 章全连接层、第 5 章反向传播、第 6.6 节梯度消失;不依赖第 8 章卷积可跳过9.7 的 PyTorch 代码与参数手算可跳过,不影响 9.3—9.6 的主线

前面的网络把每个输入当作互不相关的样本:一张图、一行特征。可语言、语音、股价、心电图都是序列(sequence),第 3 个字的意思取决于前 2 个字。本章从最朴素的循环网络(recurrent neural network)讲起,一直讲到它为什么被注意力(attention)取代。

9.1顺序就是信息

把「我打你」三个字打乱成「你我打」,字一个没少,意思却没了。序列数据和普通表格的差别不在元素本身,而在元素之间的排列。它有三个必须正面处理的性质:长度可变、顺序敏感、存在长程依赖。

  • 长度可变。一句话 3 个字,一段话 3000 个字。网络不能假设输入永远是固定长度。
  • 顺序敏感。交换两个元素会改变含义,甚至直接改变标签。
  • 长程依赖。第 100 个词可能指代第 3 个词出现的实体,中间隔了 97 个词。

具体感受一下长度:16 kHz 采样率的 10 秒音频是 160,000 个采样点;一篇 800 字的文章按字切分是 800 个 token(token);同一篇文章按词切分大约 500 个 token。处理它们的网络必须能在几百到几十万个时间步上工作。

如果把每个时间点单独喂给第 4 章的全连接网络,会发生什么?同一个字,不管前面出现过什么,得到的输出完全一样。它没有记忆。要让输出依赖历史,网络需要一个随位置更新的内部状态。另一个关键决定是共享参数(parameter sharing):识别「昨天」是时间词的能力,不应该在位置 1 和位置 2 各学一遍。一个长 100 步的序列如果每步用一套独立权重,就需要 100 套;循环网络只保留一套,在每个时间步重复使用。这既省参数,也让在短序列上学到的模式能迁移到长序列。

9.2隐藏状态:一句被压缩的笔记

循环神经网络(recurrent neural network,RNN)的做法只有一句话:把上一步的隐藏状态(hidden state)和这一步的输入放在一起,算出新的隐藏状态。

ht = tanh(Wxh xt + Whh ht−1 + bh)
yt = Why ht + by

xt 是第 t 步的输入向量,ht 是第 t 步的隐藏状态。按第 2 章的约定,单样本写成 Wx + b,矩阵乘在左边:第 2.2 节把 Wx 读成「每一行与输入做一次点积」,第 2.3 节把一批样本摞成矩阵。这里 xt 的形状是 5000×1,Wxh 是 128×5000,把输入映射进隐藏空间;Whh 是 128×128,把上一步的记忆带进来。两者相加后过 tanh,把每个分量压到 −1 到 1 之间。一次处理 B 条序列时,把每个时间步的输入摞成 (B, 5000) 的 X,批量形式就是 XWxhT + b,每一行是一个样本的新状态。

隐藏状态就是网络的记忆。假设词表 5000、隐藏维度 128:Wxh 是 128×5000 的矩阵,640,000 个参数;Whh 是 128×128,16,384 个;Why 是 5000×128,640,000 个;再加上偏置,一共 1,301,512 个参数。注意这个数字和序列长度无关:处理 10 个词和处理 10,000 个词,用的是同一套 130 万个参数。

核心隐藏状态不是录像带。它是一个固定长度的向量。上面的例子里,不管读了多少内容,记忆永远只有 128 个数。读一本 10 万字的小说和读一句话,占用的记忆一样大。信息必须被有损压缩——这正是后面所有困难的根源。

h0 通常初始化为全零。每读一个 token,就覆盖一次 h。上一次的记忆不会原样保留,它被矩阵乘法和 tanh 揉进了新的向量里。

9.3按时间展开的计算图

把循环按时间画开,RNN 就变成一个很深的前馈网络:第 t 层把第 t−1 层的输出和当前输入一起作为输入。这个图叫按时间展开的计算图(unrolled computational graph)。所有层共享同一组 Wxh、Whh、Why。

训练用反向传播的变体,叫沿时间反向传播(backpropagation through time,BPTT)。设 zt = Wxh xt + Whh ht−1 + bh 是 tanh 之前的输入,那么从第 t−1 步到第 t 步的雅可比矩阵(Jacobian)是:

∂ht/∂ht−1 = diag(1 − tanh²(zt)) Whh

∂ 读作偏导(partial derivative),diag 是对角矩阵(diagonal matrix)。梯度沿时间回传,每退一步就左乘这个雅可比的转置 JtT。从第 T 步一路代回第 1 步,∂L/∂h1 就是 T−1 个 JtT 的连乘。diag 那一项是 tanh 的导数,最大为 1,饱和时接近 0;Whh 的特征值(eigenvalue,矩阵在某方向上的缩放倍数)决定记忆被放大还是缩小。

这个连乘的后果,第 6.6 节已经算过:每步的因子略小于 1,乘积就随步数指数衰减;略大于 1,就指数放大。RNN 不需要重算一遍,只需要注意两件事。第一,因子不是标量,而是「tanh 导数 × 同一个 Whh」;tanh 一饱和,导数接近 0,再大的 Whh 也救不回来。第二,每一步乘的是同一个矩阵,同一组特征值被沿时间反复使用 T 次,序列越长,衰减或放大越极端。这就是梯度消失(vanishing gradient)与梯度爆炸(exploding gradient)在循环网络里的具体形态。

实践中对付爆炸靠梯度裁剪(gradient clipping):把整个梯度向量的范数限制在 1.0 以内。对付消失则要靠结构改动,也就是下一节的门控。普通 RNN 在实践中的有效记忆通常只有 10 到 20 步,超过这个范围,远处的信息就学不进去了。

9.4LSTM 与 GRU:给记忆装上门

长短期记忆网络(long short-term memory,LSTM)在 1997 年提出,核心是把状态拆成两条:隐藏状态 ht 和细胞状态(cell state)ct。ct 像一条传送带,信息可以几乎不变地沿着它向前走。三个门(gate)控制谁上车、谁下车。

ft = σ(Wf[ht−1, xt] + bf)
it = σ(Wi[ht−1, xt] + bi)
c̃t = tanh(Wc[ht−1, xt] + bc)
ct = ft ⊙ ct−1 + it ⊙ c̃t
ot = σ(Wo[ht−1, xt] + bo),  ht = ot ⊙ tanh(ct)

方括号表示两个向量首尾拼接(concatenation)。σ 是 sigmoid,输出 0 到 1。遗忘门(forget gate)ft 决定旧记忆保留多少:接近 1 就原样保留,接近 0 就清空。输入门(input gate)it 决定新信息写入多少。输出门(output gate)ot 决定当前细胞状态有多少暴露给 ht。⊙ 是逐元素相乘。

关键在第四行:ct 是加法。反向传播时,梯度沿细胞状态回传只需要乘遗忘门,∂ct/∂ct−1 = ft。如果网络学到 ft=0.99,1000 步后梯度还有 0.991000 ≈ 4.3×10−5;普通 RNN 若每步 0.9,1000 步后是 10−46,早就没有任何信号。遗忘门接近 1 时,这条路径近似恒等映射,梯度可以畅通地穿过几百步。

门控循环单元(gated recurrent unit,GRU)是 2014 年的简化版。它把细胞状态和隐藏状态合并,只用两个门:重置门(reset gate)rt 和更新门(update gate)zt。

rt = σ(Wr[ht−1, xt] + br)
zt = σ(Wz[ht−1, xt] + bz)
h̃t = tanh(Wh[rt ⊙ ht−1, xt] + bh)
ht = (1 − zt) ⊙ ht−1 + zt ⊙ h̃t

更新门直接在旧状态和新候选之间做插值。GRU 的参数比 LSTM 少:输入 128 维、隐藏 128 维时,LSTM 有 4 组门矩阵共 131,584 个参数,GRU 只有 3 组共 98,688 个,少 25%。在多数任务上两者效果接近,GRU 训练更快,LSTM 在需要精确计数的长序列上有时更稳。

模型状态门参数量(输入 128、隐藏 128)有效记忆
RNNh无33,024约 10—20 步
LSTMh、c遗忘、输入、输出131,584约数百步
GRUh重置、更新98,688约数百步
常见误解「LSTM 解决了梯度消失,所以它能记住任意长的依赖。」门控只是缓解,不是消除。遗忘门是学出来的,大多数时候略小于 1:0.99 的遗忘门在 1000 步后只剩 4.3×10−5,0.95 在 1000 步后只剩 5.3×10−23。而且固定 128 维的细胞状态本身也装不下任意多信息。LSTM 把可用记忆从十几步推到几百步,但没有推到无限。

9.5序列到序列

把两个 RNN 首尾接起来,就得到序列到序列(sequence-to-sequence,seq2seq)模型。编码器(encoder)读入源序列,最后一个隐藏状态作为上下文向量(context vector);解码器(decoder)从这个向量出发,一个 token 一个 token 地生成目标序列。

p(y1,…,yM | x1,…,xT) = ∏t=1M p(yt | y1,…,yt−1, c)

∏ 是连乘(product);这里的 c 是上下文向量(context vector),与 9.4 的细胞状态同名不同物。训练时解码器每一步的输入是上一个正确 token(teacher forcing),推理时换成自己上一步的输出。2014 年 Sutskever 等人的英法翻译模型用了 4 层 LSTM、每层 1000 个单元,在当时的 WMT 数据上把 BLEU 推到 30 以上。

瓶颈很快暴露:不管源句多长,编码器只交出一个固定向量。若它是 512 维,翻一个 30 词的句子,平均每个词只分到 17 个数。句子到 50 词、80 词,细节被挤掉,BLEU 随长度明显下滑。解码器没有能力回头查原文,只能凭这个被压缩的摘要回忆。

9.6注意力为什么赢了

注意力(attention)在 2014 年由 Bahdanau 等人引入翻译。做法是让解码器每一步都回头看编码器的全部隐藏状态,而不是只看最后一个。解码器当前状态和每个编码器状态算一个分数,softmax 归一化成权重,再对所有状态加权求和,得到一个专门为当前步定制的上下文向量。

αt,s = softmaxs(score(ht, ss)),  ct = Σs αt,s ss

Σ 是求和(sum);score 是打分函数(score function),给匹配度打分。这一步把固定长度的瓶颈换成了可变长度的查表:源句 5 个词就查 5 个位置,50 个词就查 50 个。解码器在生成每个词时,可以重点看它需要的那几个源词。

2017 年的 Transformer 更进一步,干脆去掉循环,只用自注意力(self-attention)。基础版是 6 层、512 维、8 个注意力头。所有位置可以同时计算,一个 1000 token 的序列不再需要 1000 次串行矩阵乘法;代价是注意力矩阵有 1000×1000 = 100 万个分数,计算量随长度平方增长。

这就是注意力取代循环的两个理由。其一,路径短:信息从第 1 个位置到第 1000 个位置,RNN 要经过 1000 次状态更新,注意力只要 1 层。其二,可并行:RNN 的第 t 步必须等第 t−1 步算完,GPU 的几千个核心大部分时间在等;注意力把所有位置放进一个大矩阵乘法,正好喂饱 GPU。

循环网络没有消失。流式语音识别、传感器信号、边缘设备上的小模型仍然爱用它:每来一个新样本,只需一次常数时间 O(1) 的状态更新和固定大小的内存,不需要保存全部历史。选择取决于约束,而不是谁更新。

9.7把一个小模型跑起来

如果你要自己训练一个字符级语言模型,下面这段 PyTorch 代码是一个能跑的最小骨架。它每个小批量(mini-batch)读入 32 条长度 35 的 token 序列,用前 35 个 token 预测后 35 个,并把梯度范数裁剪到 1.0。

python
import torch, torch.nn as nn

vocab, emb, hid = 5000, 64, 128

class CharRNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb)
        self.rnn = nn.LSTM(emb, hid, num_layers=2, batch_first=True)
        self.head = nn.Linear(hid, vocab)

    def forward(self, x, h=None):
        e = self.emb(x)                 # (B, T, 64)
        out, h = self.rnn(e, h)         # (B, T, 128)
        return self.head(out), h        # (B, T, 5000)

model = CharRNN()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
lossf = nn.CrossEntropyLoss()

batch = torch.randint(0, vocab, (32, 36))
x, y = batch[:, :-1], batch[:, 1:]  # 用前 35 个预测后 35 个

for step in range(200):
    logits, _ = model(x)
    loss = lossf(logits.reshape(-1, vocab), y.reshape(-1))
    opt.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    opt.step()

print(sum(p.numel() for p in model.parameters()))  # 1196424

这段模型的实际参数量是 1,196,424:词嵌入 5000×64 = 320,000,两层 LSTM 共 231,424,输出层 128×5000+5000 = 645,000。在单张消费级显卡上,这个规模每秒能处理几千个 token。

几条能省掉几小时调试时间的经验:序列按长度分桶(bucketing),别让一个小批量(mini-batch)里最长的序列把其余都 padding 到很长;用截断的 BPTT,每 35 步回传一次,否则显存随序列长度线性增长;学习率从 1e-3 的 Adam 开始;监控梯度范数,长期低于 1e-4 说明梯度消失,长期高于 10 说明需要更强的裁剪。真实训练时,把所有训练序列完整过一遍叫一轮(epoch);上面为了骨架最短,只反复用同一个固定的小批量。

先跑通再调结构拿到一个新序列任务,先用上面的两层 LSTM 跑 200 步,确认损失能从 ln(5000) ≈ 8.52 降到 5 以下。如果降不下去,先检查输入和目标是否错开了一位,再检查 padding 是否被算进了损失。结构问题通常排在数据问题之后。

9.9局限与交接

把 RNN 的局限压缩成三条。第一,串行:第 t 步依赖第 t−1 步,训练时无法在时间维度并行,序列多长就要等多久。第二,路径长:梯度从第 1000 步传回第 1 步要穿过 1000 次乘法,门控只能把衰减变慢,不能把路径变短。第三,状态定长:所有历史被压进一个向量,细节必然丢失,信息量有硬上限。注意力分别从这三个点切入:所有位置并行计算,任意两个位置之间只隔一层,并且直接访问全部历史而不是压缩后的摘要。
