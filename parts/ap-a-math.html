A.1向量与点积

向量(vector)可以看成一支箭头,也可以看成一串有序的数。二维向量 (3, 4) 的意思是:沿 x 走 3,沿 y 走 4。它的长度是 √(3²+4²)=5。神经网络里的一个样本、一层激活、一个词的嵌入(embedding),本质上都是向量;一张 28×28 的灰度图也能拉成 784 维向量。

两个向量 a 和 b 的点积(dot product)有两种等价写法:

a · b = a1b1 + a2b2 + … + anbn = |a||b|cos θ

左边是“逐项相乘再相加”,右边是“长度乘长度乘夹角余弦”。左边适合写代码,右边适合想几何。

几何直觉:把 b 投影到 a 的方向上,投影长度是 |b|cos θ;点积就是这个投影长度再乘以 |a|。同向时 cos θ=1,点积最大;垂直时 cos θ=0,点积为 0;反向时点积为负。所以点积衡量的是两个向量的对齐程度,而不是它们各自的绝对大小。

算一个具体例子。w=(2, -1),x=(3, 4):w·x=2×3+(-1)×4=2。|w|=√5≈2.236,|x|=5,cos θ=2/(2.236×5)=0.179,θ≈79.7°。x 在 w 方向上的投影长度是 2/2.236≈0.894,很短,说明这两个向量几乎垂直。

它在神经网络的哪里出现:一个神经元的加权和是 z=w·x+b,点积就是“每个输入乘一个权重再相加”;注意力(attention)里的打分 q·k 是点积;判断两个词向量像不像,用余弦相似度(cosine similarity),它只是把点积除以两个长度。卷积核在图像上滑动时,每个位置的响应也是一个小块与卷积核的点积。

A.2矩阵乘法

矩阵(matrix)是向量的批量版本,也是一个空间变换。一个 m×n 矩阵把 n 维向量变成 m 维向量。矩阵乘法的规则只有一句:左边矩阵的每一行,和右边矩阵的每一列做点积。式子里的 Σk 是求和(sum),即对 k 逐项相加。

Cij = Σk AikBkj,  (m×n)(n×p)=m×p

具体算一遍:

[[1,2],[3,4]] × [[5,0],[6,1]] = [[17,2],[39,4]]

17=1×5+2×6,2=1×0+2×1,39=3×5+4×6,4=3×0+4×1。每个输出格子都是一次长度为 2 的点积;整个乘法做了 8 次乘加。注意 [[1,2],[3,4]]×[[5,0],[6,1]] 与交换顺序后的结果并不相同,矩阵乘法不满足交换律,很多时候两个矩阵连形状都对不上。

神经网络把它用在批量上。32 个样本、每个 128 维,记作 X(32×128);权重 W(128×64)。Z=XW 的形状是 32×64,每个样本得到 64 个神经元的加权和。这一次乘法做 32×128×64=262,144 次乘加。若再加偏置 b(长度 64),Z+b 会把 b 广播到 32 行,每一行都加同一个偏置。

它在神经网络的哪里出现:每一个全连接层都是一个矩阵乘法;Transformer 的 QKT 是矩阵乘法;卷积可以用 im2col 展开成矩阵乘法;嵌入表查表等价于用一个 one-hot(独热:只有一位为 1,其余为 0)向量乘嵌入矩阵。矩阵乘法之所以是深度学习的地基,是因为 GPU 最擅长把大量点积并行算完。

一个 batch 有 32 个样本,每个样本 128 维;权重矩阵 W 的形状是 128×64,没有 bias。XW 的形状是什么?

A.3导数、导数表与链式法则

导数(derivative)是函数在某一点的瞬时斜率。把曲线放大到足够近,它看起来像一条直线,这条直线的斜率就是导数,记作 f'(x) 或 dy/dx。导数为正,函数在上升;为负,函数在下降;为 0,切线水平。神经网络训练要找的是损失函数的谷底,所以导数告诉你“往左还是往右,坡度多陡”。

这本书用到的导数都在下表里。表里的 σ 是 sigmoid 函数(sigmoid),它把任意实数压到 0—1 之间;tanh 是双曲正切(hyperbolic tangent),形状相同,把它压到 −1—1 之间。不用一次背完,先看第三列:每一个导数都能对应到网络里的一个具体位置。

ReLU(x)=max(0,x)0 (x<0),1 (x>0)隐藏层最常见的激活函数

表里最该记住的是 sigmoid 的导数 σ(x)(1-σ(x)):它的最大值只有 0.25,出现在 x=0;当 x 走到 ±6,导数降到 0.0025 左右。这解释了为什么 sigmoid 堆深了会梯度消失(gradient vanishing)。tanh 的导数最大是 1,比 sigmoid 好一点,但两端同样饱和。ReLU 在正半轴的导数恒为 1,所以深层网络更常用它;x=0 处严格说不可导,工程上取 0 或 1 都可以。

链式法则(chain rule)处理复合函数。若 y=f(u),u=g(x),则 dy/dx=(dy/du)(du/dx)。一句话:把沿路的斜率乘起来。复合多少层就乘多少次,顺序不重要,但不能漏掉任何一段。

例子:y=(3x+1)²。令 u=3x+1,dy/du=2u,du/dx=3,所以 dy/dx=6(3x+1)。在 x=1 处等于 24。展开验证:y=9x²+6x+1,导数 18x+6,在 x=1 处也是 24。两种算法一致,但链式法则不用展开,网络里几百万个参数也不可能展开。

多元函数把导数拆成偏导数(partial derivative):对某个变量求导时,其他变量当常数。把所有偏导数排成向量,就是梯度(gradient)。梯度指向函数上升最快的方向;沿负梯度走,函数下降最快。这就是梯度下降(gradient descent)的全部几何含义,学习率(learning rate)只决定每一步走多远。

它在神经网络的哪里出现:反向传播(backpropagation)不是新数学,它就是链式法则在计算图上从输出往输入乘一遍。softmax 加交叉熵的梯度能化简成 p-y,也是链式法则把 softmax 的雅可比和交叉熵的导数乘起来后消掉的结果。PyTorch 的 loss.backward() 做的就是这件事。

A.4对数:把乘法变成加法

对数(logarithm)回答的是“底数要乘自己多少次才等于这个数”。log₂8=3,因为 2³=8;ln e=1;log₁₀1000=3。机器学习默认用自然对数 ln,底数是 e≈2.718;信息论里常用 log₂,单位是比特(bit)。自然对数的单位叫纳特(nat),1 纳特=1/ln2≈1.4427 比特。

两条性质最常用:log(ab)=log a+log b,log(ab)=b log a。第一条把乘法变成加法。为什么这件事重要?一个长度为 1000 的句子,概率是 1000 个数相乘;每个数都小于 1,乘到后面计算机直接下溢成 0。取对数后变成 1000 个数相加,既不会下溢,也好求导。

概率 p 在 (0, 1] 之间,所以 ln p≤0,-ln p≥0。p=1 时 -ln p=0;p=0.5 时 0.693;p=0.1 时 2.303;p=0.01 时 4.605。概率每差 10 倍,损失差 2.303 纳特。ln1000≈6.908 纳特,换成比特是 6.908/ln2≈9.966 比特。

它在神经网络的哪里出现:交叉熵、对数似然(log-likelihood)、困惑度(perplexity,等于平均交叉熵取 exp)、数值稳定的 logsumexp、熵(entropy)和 KL 散度(KL divergence)。语言模型的损失常报“每 token 多少纳特”,再取 exp 就是“模型平均在多少个候选词里犹豫”:平均损失 2.303 纳特,困惑度就是 e2.303≈10,相当于在 10 个词里挑一个。

A.5softmax 与交叉熵

分类网络的最后一层输出 logits,它们只是未归一化的实数分数,不是概率:可以是负数,加起来也不等于 1。softmax 把一组 logits 变成概率:

pi = ezi / Σj ezj

先取指数,保证每个数都是正的;再除以总和,保证加起来等于 1。指数还有一个效果:大的 logit 会被放大。logits (2.0, 1.0, 0.1) 的指数是 7.389、2.718、1.105,和是 11.212,概率是 0.659、0.242、0.099。第一类比第二类只高 1.0,概率却高了 2.7 倍。

softmax 只关心差值。所有 logits 同时加 100,分子分母同乘 e100,概率完全不变。实际代码先减去最大值再取指数,就是为了避免 e1000 溢出成无穷大。同理,把所有 logits 同时乘以 2,分布会变尖;除以 2,分布会变平。前者就是温度(temperature)小于 1,后者是温度大于 1。

交叉熵(cross-entropy)衡量“模型给正确答案的概率有多低”:

L = -ln pt = -Σi yi ln pi

t 是正确类别,y 是 one-hot 标签。模型给正确类 0.659,损失 0.417;给 0.099,损失 2.313。猜得越准,损失越接近 0;给正确答案 0 概率,损失趋向无穷大。所以交叉熵对“自信地答错”惩罚极重。

把 softmax 和交叉熵接在一起求导,结果会化简成非常干净的一行:∂L/∂zi=pi-yi(∂ 是偏导,只对一个变量求导)。正确类的那一项是 pt-1,其他类就是 pi。比如上面的例子,梯度是 (-0.341, 0.242, 0.099),三个数加起来正好是 0。这个梯度有界,不会因为指数爆炸;这也是分类网络通常用交叉熵而不是“softmax 后再套均方误差”的原因之一。

推导:softmax 加交叉熵为什么得到 p-y

记 S=Σjezj,则 pt=ezt/S。对 zi 求导时,分子只在 i=t 时变化,分母永远变化:

∂pt/∂zi = pt(δit-pi),其中 δit 在 i=t 时为 1,否则为 0。

L=-ln pt,所以 ∂L/∂zi=-(1/pt)·∂pt/∂zi=pi-δit。写成向量就是 p-y。整段推导只用了链式法则和商的求导。

它在神经网络的哪里出现:图像分类的输出层、语言模型预测下一个 token、注意力权重的归一化、对比学习里的温度 softmax。大模型采样时调的 temperature 就是这里的缩放系数:T 大,分布更平,输出更随机;T 小,分布更尖,更接近贪心。

A.6期望与方差

期望(expectation)是概率加权的平均。离散情形 E[X]=Σ pixi。掷一个均匀骰子,期望是 (1+2+3+4+5+6)/6=3.5;它不是某个可能结果,而是长期平均。期望是线性的:E[aX+b]=aE[X]+b,E[X+Y]=E[X]+E[Y],后一条不要求 X、Y 独立。

方差(variance)衡量偏离平均的程度:Var(X)=E[(X-E[X])²]=E[X²]-E[X]²。标准差(standard deviation)是方差的平方根,和原数据同单位,读起来更直观。

算一个训练中的例子。60% 的样本损失 0.2,40% 的样本损失 1.2。期望损失 E=0.6×0.2+0.4×1.2=0.6。方差=0.6×(0.2-0.6)²+0.4×(1.2-0.6)²=0.096+0.144=0.24,标准差≈0.49。平均值 0.6 看起来不差,但标准差 0.49 说明有一批样本的损失是平均值的两倍,模型并没有对所有人都好。

它在神经网络的哪里出现:训练损失其实是数据分布上的期望,你只能用一个 mini-batch 估计它。若单个样本的损失方差是 σ²,batch 大小为 B 的均值方差是 σ²/B,标准差降到 σ/√B。B=64 时噪声标准差是单样本的 1/8。这就是为什么 batch 越大,梯度曲线越平滑,但每一步也越贵;也是为什么把 batch 从 64 加到 256 只能把噪声减半,收益递减。

初始化也用到方差。He 初始化让权重方差为 2/fan_in(fan_in 是输入维度,fan-in),Xavier 用 2/(fan_in+fan_out),目的是让每一层激活的方差大致保持不变;批归一化(BatchNorm)则直接把每个特征标准化到均值 0、方差 1。训练时看到的 loss 曲线抖动,一半来自采样,一半来自学习率。

A.7条件概率

条件概率(conditional probability)问的是“已知 B 发生,A 发生的概率是多少”:

P(A|B) = P(A∩B) / P(B),  P(B)>0

变形得到乘法法则 P(A∩B)=P(A|B)P(B),其中 ∩ 是交集(intersection),表示两件事同时发生。如果 A、B 独立,P(A|B)=P(A),联合概率就是两者相乘。贝叶斯公式(Bayes' theorem)只是把乘法法则反过来用:

P(A|B) = P(B|A)P(A) / P(B)

算一个具体例子。1000 封邮件里 200 封是垃圾邮件;50 封含“免费”,其中 40 封是垃圾邮件。P(垃圾|免费)=40/50=0.8;P(免费|垃圾)=40/200=0.2;P(免费)=50/1000=0.05;P(垃圾)=0.2。贝叶斯给出 0.2×0.2/0.05=0.8,和直接数出来一致。注意 0.8 和 0.2 是两个方向的条件概率,不能混。

它在神经网络的哪里出现:分类器输出的就是 P(y|x);训练最大化条件似然,等价于最小化交叉熵。语言模型把整句概率分解成 P(x₁,…,xT)=∏ P(xt|x<t),每一步都是“给定前文,下一个词的条件概率”。扩散模型、机器翻译、语音识别都在建模某种条件分布。评估时的精确率(precision)是 P(真实为正|预测为正),分母是模型预测为正的样本;召回率(recall)是 P(预测为正|真实为正),分母是真实为正的样本。两者分母不同,不能互相替代。

1000 封邮件中 200 封是垃圾邮件,50 封含“免费”,其中 40 封是垃圾邮件。P(垃圾|免费) 是多少?

A.8把十件工具接成一次训练

一次前向传播:样本 x 与权重 W 做矩阵乘法,得到 logits z;softmax 把 z 变成概率 p;交叉熵取 -ln pt 得到损失。一次反向传播:链式法则从损失出发,依次乘上交叉熵、softmax、矩阵乘法的局部导数,得到每个权重的梯度。一次参数更新:沿负梯度走一小步,学习率 η 决定步长。整个训练循环就是这三步的重复。

最后给一个可操作的检查顺序。手推一个网络的梯度时:先写出前向的每一步,标出形状;再写出损失;然后从损失往回,每经过一个节点就乘上它的局部导数;最后检查梯度形状和参数形状是否一致。形状对不上,几乎一定是某一步的矩阵转置或 batch 维丢了。数值对不上,先用有限差分做一次数值梯度检查:把某个参数加 1e-4,看损失变化多少,和解析梯度比。
