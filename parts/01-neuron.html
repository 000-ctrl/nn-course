读前第 00 章的「函数、参数」与符号速查页 §.1 的 Σ、∂;导数只需知道「变化率」,1.4、1.6 用到,正式讲法在第 03 章。可跳过1.3 的几何解释、1.6 的 numpy 代码块与「点开看梯度」折叠,跳过不影响主线。

神经网络听起来像一门关于大脑的学问,但它的基本零件简单到可以在纸上算完:一串输入、一组权重、一个偏置、一次加权求和,再套一个非线性函数。本章只做一件事——把这个零件彻底拆开,让你能亲手调它、看它出错,并且知道它为什么必然出错。后面所有网络,都是把这个零件复制上万份、接成多层。

1.1从生物神经元到数学模型

生物神经元(biological neuron)有树突(dendrite)、细胞体(soma)、轴突(axon)和突触(synapse)。树突接收来自其他神经元的信号,细胞体把这些信号汇总,轴突把结果传出去,突触是连接处的接口。人脑约有 860 亿个神经元,常用估计约有 100 万亿条突触连接,平均每个神经元接收上千条。信号表现为电脉冲(spike),强弱由放电频率编码:输入越强,放电越密。

这一套机制里,真正可计算的部分只有三件事:多路输入、按连接强度加权求和、超过阈值才输出。1943 年 McCulloch 与 Pitts 把这三件事抽出来,得到第一个人工神经元(artificial neuron)模型。它当然不是大脑的复制品,但足够作为一块可训练的计算积木。

1.2加权和:z = w·x + b

把输入写成向量(vector)x = (x₁, x₂, …, xₙ),每个输入配一个权重(weight) wᵢ。权重表示这条输入有多重要,正权重鼓励神经元激活,负权重抑制它。把所有输入乘上各自权重再相加,得到加权和(weighted sum):

z = w · x + b = w1x1 + w2x2 + … + wnxn + b

再加一个非线性函数 f,就得到神经元的输出 a = f(z)。公式里每一项都在做同一件事:某个输入乘以它对结果的影响,然后累加。

看一个具体例子。用两个特征判断一套房子是否值得看:面积(单位:百平方米)与到地铁的步行时间(单位:10 分钟)。取权重 w₁ = 1.8、w₂ = −0.9、偏置 b = −0.4。对一套 120 平方米、步行 5 分钟的房子,x = (1.2, 0.5),于是 z = 1.8×1.2 − 0.9×0.5 − 0.4 = 1.31。套上 S 形函数(sigmoid,把任意数压到 0—1)后 a ≈ 0.788,表示模型给出 78.8% 的倾向。

偏置(bias)b 是不依赖任何输入的常数。它最重要、也最容易被初学者忽略的作用,是把决策边界(decision boundary)整体推开。取 w = (1, 1),当 b = 0 时,分界线是 x₁ + x₂ = 0;当 b = +2 时,分界线变成 x₁ + x₂ = −2,整条线朝负方向平移了两个单位,于是原来落在边界另一侧的一大片点被划进正类。你可以把 b 想成一只从背后推桌子的手:它不改变桌子的朝向,只改变桌子离原点的距离。

工程上常把偏置吸收进权重:给神经元加一个恒为 1 的输入 x₀ = 1,令 w₀ = b,则 z = Σ(西格玛,求和) wᵢxᵢ 从 i = 0 开始。这样代码里只剩一次向量点积,少一个特判。双输入神经元因此有 3 个参数(parameter):2 个权重加 1 个偏置。

1.3点积在几何上做了什么

公式 w·x 叫点积(dot product)。它有两种读法。代数的读法是逐项相乘再相加;几何的读法是:

w · x = |w| |x| cos θ

其中 θ 是两个向量之间的夹角。这个式子说明:点积等于 x 在 w 方向上的投影(projection)长度,再乘以 w 的长度。取 w = (3, 4),x = (4, 3):两者长度都是 5,点积是 3×4 + 4×3 = 24,于是 cos θ = 24/25 = 0.96,夹角约 16.3°;x 在 w 上的投影长度是 24/5 = 4.8。

把权重看成神经元"偏好的方向",z 就是在问:输入沿着这个方向走了多远。夹角为 0,点积最大,神经元最兴奋;夹角 90°,点积为 0,在 b = 0 时输入恰好落在分界线上;夹角 180°,点积为负,神经元被抑制。高维空间里没有肉眼可见的夹角,但 cos θ 仍然是相似度(similarity):两个向量方向越一致,点积越大。后面的注意力机制用点积给词与词打分,用的就是这条几何直觉。

1.4激活函数:把 z 压进可用的范围

只有 z 时,神经元输出可以任意大,也不方便解释。激活函数(activation function)把 z 映射到一个固定范围,并引入非线性。单个神经元里它不改变分界线的位置,但在多层网络里,正是它让网络能表达曲线——这一点在第 04 章会看到。

阶跃函数(step function)最简单:z ≥ 0 输出 1,否则输出 0。它的导数(derivative,函数的变化率)几乎处处为 0,在 z = 0 处不可导;导数的完整讲法在第 03 章。这意味着它无法用梯度下降(gradient descent,梯度指函数增长最快的方向)训练:参数动一点点,输出不变,梯度给不出该往哪走。

sigmoid 把任意实数压到 (0, 1):

a = σ(z) = 1 / (1 + e−z)    a′ = σ(z)(1 − σ(z))

导数在 z = 0 处取最大值 0.25,向两侧迅速衰减。具体数字:z = 2 时 a = 0.881,导数 0.105;z = 4 时 a = 0.982,导数 0.0177;z = 6 时导数只剩 0.0025。两端这种"怎么推都不动"的状态叫饱和(saturation)。

tanh 把输出压到 (−1, 1),且以 0 为中心,导数 1 − tanh²(z),在 0 处最大为 1。tanh(2) = 0.964,导数 0.0707;tanh(4) 的导数只有 0.00134,同样会饱和。零中心让下一层收到的输入均值为 0,通常比 sigmoid 更好训练。

修正线性单元(ReLU)是 max(0, z):正区导数恒为 1,负区恒为 0,计算只要一次比较。它没有上界饱和,是隐藏层的默认选择。代价是死亡 ReLU(dying ReLU):如果某个神经元的 z 对所有样本都为负,它的梯度恒为 0,权重再也收不到更新,这个单元就永久失效。学习率(learning rate)过大时,几十个 ReLU 可能同时死亡。

1.5一个神经元的天花板

做二分类时,你只关心 a 落在阈值(threshold)的哪一侧:sigmoid 用 0.5,tanh 用 0,ReLU 用 0。这几个激活函数都是单调不减的,所以条件等价于 w · x + b > 0。换句话说,分类边界就是方程 w · x + b = 0 的解集:二维里是一条直线,三维里是一个平面,高维里是一个超平面(hyperplane)。如果两类点能被这样一条直线完全分开,它们就叫线性可分(linearly separable)。

因此,一个神经元就是一个线性分类器(linear classifier)。它能做的全部事情,是用一条直线把平面切成两半。它无法表示"两个特征相同时输出 0、不同时输出 1"这种关系。后者叫异或(XOR):四个点 (0,0)、(1,1) 属于 0 类,(1,0)、(0,1) 属于 1 类。两类点的凸包(convex hull,包住所有点的最小凸形)在中心相交,任何一条直线都只能正确分对其中的 3 个点,准确率上限是 75%。

这不是训练不够,也不是学习率没调好,而是模型容量(model capacity)不够。参数数量可以算清楚:n 维输入接 1 个神经元有 n + 1 个参数;一层 m 个神经元接收 n 维输入,有 m(n + 1) 个参数。例如 784 维的图像接 128 个神经元,共有 128 × 785 = 100,480 个参数——即使有 10 万个参数,每个神经元的边界仍然是一个超平面。

常见误解给单个神经元换上 sigmoid 或 ReLU,它就能拟合 XOR、画出弯曲的边界。激活函数只改变 a 的数值尺度,不改变 z = 0 这条线的位置;分类只用到 z 的符号,所以边界仍是一条直线。要让边界弯折,至少需要两层:隐藏层用多条直线切出多个半平面,输出层再把这些半平面组合起来。这是第 04 章的主题。

1.6用 20 行 numpy 训练它

训练一个二分类神经元,需要定义一个损失(loss)来衡量输出与标签差多远。二分类用二元交叉熵(binary cross-entropy,ln 为自然对数):对错得越离谱,值越大。

L = −[ y ln a + (1 − y) ln(1 − a) ]

把 L 对 z 求导,结果干净得出奇:∂(偏)是偏导,∂L/∂z = a − y。再往参数上传,∂L/∂wᵢ = (a − y)xᵢ,∂L/∂b = a − y。也就是说,每个权重该往哪边调、调多少,只取决于"预测减标签"这个误差,再乘上对应的输入。这就是反向传播(backpropagation)在一个神经元上的全部内容;第 05 章会把它推广到多层。

点开看这两个梯度怎么来的

对 sigmoid,σ′(z) = a(1 − a)。把 L 对 a 求导:

∂L/∂a = −y/a + (1 − y)/(1 − a) = (a − y) / [a(1 − a)]

再用链式法则(chain rule)乘上 σ′(z) = a(1 − a),分母正好约掉:

∂L/∂z = (a − y) / [a(1 − a)] × a(1 − a) = a − y

最后 z 对 wᵢ 的偏导就是 xᵢ,对 b 的偏导是 1,于是得到正文里的两个式子。

python
import numpy as np

rng = np.random.default_rng(0)
# 两类点:0 类在左上,1 类在右下
n = 120
X0 = rng.normal([-1.0, 0.8], 0.45, size=(n // 2, 2))
X1 = rng.normal([ 1.0,-0.8], 0.45, size=(n // 2, 2))
X  = np.vstack([X0, X1])
y  = np.r_[np.zeros(n // 2), np.ones(n // 2)]

w = np.zeros(2)
b = 0.0
lr = 0.5
for epoch in range(300):
    z = X @ w + b
    a = 1 / (1 + np.exp(-z))        # sigmoid
    dz = a - y                      # 损失对 z 的梯度
    w -= lr * (X.T @ dz) / n
    b -= lr * dz.mean()

pred = (X @ w + b > 0).astype(int)
print(w, b, (pred == y).mean())
# 训练 300 轮后约 [3.5 -3.0],b≈0,准确率 1.0(随种子浮动)

这段代码在 120 个点上训练 300 轮(epoch),学习率取 0.5。两个权重训练 300 轮后大约落在 (3.5, −3.0) 附近(随随机种子浮动),偏置始终在 0 附近,训练集(training set)准确率 100%。注意它成功的前提:这两团点本来就线性可分。把数据换成 XOR,同一个脚本的准确率会停在 75% 左右,加多少轮都一样。

你现在已经拥有一个完整的、可训练的神经元:前向是 w·x + b 再套激活函数,反向是 (a − y) 乘输入,更新是减去学习率乘梯度。下一章把单个神经元排成向量、把一层排成矩阵,你会看到同样的计算如何一次处理成百上千个样本。
